# 模板库 — 教师本校模板的统一落点

每个技能的 intake 都会问「学校/学院有没有模板」。教师给的模板文件**一律放这里**，
按类别进子目录，技能执行时优先来这里找，找不到再走通用结构。

## 目录约定

| 子目录 | 放什么 | 主要消费技能 |
|---|---|---|
| `卷头/` | 试卷头、密封线、得分栏、答题卡样式（docx/pdf/图片均可） | quiz-generator、exam-pipeline |
| `审批表/` | 命题审批单、成绩分析表、教学事故认定表等行政表格 | exam-pipeline、course-design |
| `评语/` | 评语风格样例、老生评语集（脱敏后） | comment-writer |
| `申报书/` | 教改项目、课程建设、一流课程申报书的本校模板 | grant-proposal |
| `归档清单/` | 课程归档、试卷归档的材料清单与装订顺序要求 | exam-pipeline |

## 使用规则

1. **只存结构，不存内容**：模板里别留真实学生姓名、成绩、身份证号；放进来前先脱敏。
2. **命名带学校与年份**：如 `卷头/XX大学-2024版-期末卷头.docx`，学校改版时新旧并存，技能取最新年份。
3. **技能侧的口径**：intake 问到模板时先查这里；命中则在交付说明写「已套用 `templates/…`」，
   未命中则用各技能自带的通用结构，并标注「请对照贵校模板调整」。
4. **不进 git 的情形**：涉密或含未脱敏个人信息的模板不要提交（本目录已在 `.gitignore`
   留有例外位时可就地说明）。
