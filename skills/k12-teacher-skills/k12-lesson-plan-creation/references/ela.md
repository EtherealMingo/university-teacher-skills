# ELA — 课程教学法

当学科为 **ELA（英语语言艺术）** 时由 `k12-lesson-plan-creation` 加载。

## 澄清

在提出任何问题之前，先根据所有可用的对话信号评估以下各项：

**1. 州识别：** 扫描对话中的任何州信号——教师提到某个州名、使用州专属的标准代码（TEKS、SOL、OAS、CA-CCSS 等），或说"我在 [某州] 教书"。如果发现，记为 state = [州名]，并在知识图谱标准查询中作为 jurisdiction（辖区）传入。同时把默认标准框架更新为与之匹配。

**2. 年级段。** 根据年级判断适用哪个学段：
- **K–2**：基础读写——拼读/解码 或 朗读/理解（从标准推断；RF 标准 = 拼读课；RL/RI 标准 = 理解课）
- **3–5**：过渡期理解
- **6–8**：文学与修辞分析
- **9–12**：高阶分析与论证

**3. 锚文本 (Anchor text)。** 注意教师是否指定了文本。如果没有，从训练知识中
选择一篇适合该年级和标准的文本——或从知识图谱的课程材料调用中获取
（见 learning-commons-kg.md）。自己选择的文本要在第 1 节中标注为
[suggested]（建议选用）。

锚文本的材料说明要写明文本出处，让教师能把文本放到
学生面前。公有领域文本随材料包附带。受版权保护的文本
只给引用——标题、作者、日期、来源——由教师自行准备副本；在对话中
也要说明。只有在确认链接可访问后才附 URL；否则引用信息
独立成立。示例：*"Ain't I a Woman?" — Sojourner Truth, 1851 — 公有领域，
随学生页附带；全文：https://www.nps.gov/articles/sojourner-truth.htm
（已确认可访问）。*

当关键信息缺失时，提问。优先级：(1) 年级（若缺失），(2) 主题或文本（若缺失），(3) K–2 的课型（若标准未能明确），(4) 州（若无法推断）。其余一切靠推断。静默采用的默认值：45–60 分钟（K–2 可按 45 分钟）、全纳式设计、CCSS（当州识别发现州框架时被其覆盖）。

## 标准锚定

遵循 SKILL.md 中的**第 2 步 — 锚定标准**：如果 Learning Commons 知识图谱
已连接，使用 `references/learning-commons-kg.md` 的 ELA 部分；如果未连接，
依据最佳知识继续并加上免责声明脚注。

## 构建课程

**所有课程通用**
至少包含一个具体出现在学生页面上的视觉支架——
一个 `fill_table` 组织图或一套批注符号约定——登记在 `shared` 中
并通过 `from_shared` 拉取，使同一个支架也出现在教案中，
旁边配上面向教师的设计依据。

确保整体时间和每个环节的时间都切实可行——不要让课程超载。

### 年级段 — 起草前先应用

年级段是首要的结构分支。根据年级判断并应用对应结构。

#### K–2：基础读写

根据目标标准确定课型：
- **RF 标准**（基础技能）→ **课型 A：拼读/解码**
- **RL/RI 标准**（文学阅读 / 信息类阅读）→ **课型 B：通过朗读实现理解**

两种课型都以简短的拼读复习热身开场；主要侧重不同。

**课型 A — 拼读/解码（RF 标准）**

学生页面上的单词练习渲染为 `display: "large"` 的表格网格——大号字体，
孩子指着读——绝不排成段落式的单词流。某个模式的单词表
只含该模式加上已教过的字素 (graphemes)；把每个词读出来确认每个字母
都按所教规则发音。出门票让孩子向教师朗读 3–4 个目标模式的单词
（包含一个对比词，例如在 a_e 中混入短音 a）；听写单词由
教师口头读出，绝不印在孩子的出门票上。

课程范围要与请求匹配：单一模式的导入课（"一节讲 magic-e 的课"）
是一节 30–40 分钟的聚焦课——预备音热身、教该
模式、引导练习、独立练习、出门票——只覆盖一个模式（仅 a_e
本身，其余留待后续课程）。当教师点名整个类别时
（"r 控元音"），课程覆盖该类别中的不同发音——ar、or，
以及 er/ir/ur 作为同一个音处理，因为它们本来就是同一个音。
下方完整的板块流程适用于教师要求完整识字课时的情况。

所引标准要与所教技能匹配：听辨/拼合课（口头、无文字）
引用音素意识标准族（如 RF.2），解码/拼写课
引用拼读标准 (RF.3)——范围写明"仅口头辨识"的课绝不挂
解码类标准。

完整识字板块（60–80 分钟，当教师要求整个板块时）：典型弧线为
音素意识（仅口头，无文字）→ 拼读（明确的音素—字素对应；
解码与拼写结合；真词与假词）→ 可解码文本练习（只使用
已教模式加上已学高频词的连贯文本）→ 朗读（复杂的、
内容丰富的文本——非虚构至少占一半；口头的文本依赖问题）→
词汇与讨论（2 个第二层词汇 (Tier 2 words)）→ 共享写作（共同构建 1–2 个句子）→
出门票（目标模式上的一道读词题 + 一道拼词题）。

**课型 B — 通过朗读实现理解（RL/RI 标准）**

典型弧线：拼读热身（5 分钟，简短复习）→ 朗读（教师朗读锚
文本，在预设停顿点停下提口头的文本依赖问题）→ 文本依赖
讨论（口头 think-pair-share；问题从整体理解 → 关键细节 →
词汇 → 简单推理逐步推进；每个学生都要作答）→ 词汇（2 个第二层
词汇，附定义、语境、例句）→ 共享写作（用目标词共同构建
一段书面回应）→ 出门票（一道口头或简单书面的理解题）。

**K–2 不可妥协项：** 不用三线索法 (three-cueing)（不借助图画、语境或首字母
猜测来认词）；拼读练习用可解码文本 (decodable text)，不用分级读物或可预测文本；
朗读是教学性的——刻意选择的复杂、内容丰富的文本。

---

#### 3–5 年级：过渡期理解

典型弧线——按请求规模调整：导入（用一个聚焦的提示激活先前知识；
让学生直接接触文本自主探索）→ 精读（锚文本保持年级
复杂度，不降级；第一遍读大意，第二遍带着指定的批注
目的读）→ 讨论（所有学生先写后说——Think-Write-Pair-Share；问题
从整体理解 → 关键细节 → 词汇/结构 → 作者笔法逐步推进）→
词汇（2 个第二层词汇，附文本语境；学生在写作任务中使用它们）→
写作任务（文本依赖型："利用第 ___ 段和第 ___ 段的证据，解释作者
如何表现……"；3–4 年级为观点写作，5 年级为带证据的论证写作）→
出门票（一道需要推理或笔法分析的文本依赖问题）。

**3–5 不可妥协项：** 所有学生都读复杂文本——通过重读、讨论
和词汇来搭建通道，绝不换成更简单的替代文本；只用文本依赖问题；
每次讨论都先写后说。

---

#### 6–8 年级：文学与修辞分析

典型弧线——按请求规模调整：导入（引人深思的问题；简短的、暂不分享的
快速写作，学生在课尾回看）→ 精读（带着指定的
分析视角做批注——论点展开、笔法动作、支持中心思想的证据；
结对比较批注）→ 结构化讨论（Think-Write-Pair-Share 进入全班
讨论，从字面理解走向分析；8 年级或水平较好的小组可用
鱼缸讨论 (fishbowl) 或苏格拉底研讨 (Socratic Seminar)；复盘讨论质量，而不只是内容）→
词汇与笔法（1–2 个第二层词汇加一个笔法焦点——学生分析其效果，
而不只是识别）→ 写作任务（论点 + 证据 + 推理；6–7 年级示范
结构；8 年级加入反驳 (counterclaim)）→ 形成性检查（回到导入时的快速写作：
你的想法发生了什么变化，现在你会引用什么证据？）。

**6–8 不可妥协项：** 分析而非概述——任务要求一个可争辩的论点，
且必须引用文本支撑；尽可能把文学文本与信息类文本配对；
8 年级的论证写作要有反驳。

---

#### 9–12 年级：修辞成熟度与持续论证

典型弧线——按请求规模调整：导入（一个精确的、真正可争辩的问题；
学生独立写作，暂不讨论）→ 精读（带着特定分析视角做批注；
文本较短时带着不同目的读多遍；保持
复杂度——这正是意义所在）→ 学术讨论（生生之间；教师追问，
不主导；苏格拉底研讨中按行号引用具体段落；复盘内容和
讨论质量）→ 笔法与语言（一个精准的笔法动作；学生分析效果
和意图）→ 写作任务（持续的分析性或论证性回应：可争辩的论点 +
文本证据 + 分析；论证中要有反驳）→ 形成性检查（学生评估
自己的开场论点：你会补充或修改什么证据？）。

**9–12 不可妥协项：** 分析*如何*与*为何*，而不只是*什么*——在
特定修辞情境中对特定读者的效果；全文按完整难度呈现（不
绕过难段落做节选，不用概要代替原文，不预先讲解）；
11 年级起要有反驳，且修辞分析要关顾读者、目的与情境。

### 章节结构 — 所有年级段通用

1. **一览** — 在 `special` 标注块中逐字引用标准（这是唯一的逐字引用——其他地方标准一律用代码 + 简短要点）；一行课程弧线，点名各阶段及分钟数，让这节课的形状在任何细节之前可见；锚文本（标题 + 体裁 + Lexile 蓝思值（如已知），或 [suggested] 标记）；材料清单——每项平实点名（如"图片卡，18 张"）
2. **学习目标** — 大观念（持久性理解，1 句话，与文本和单元关联）；SWBAT 要点，取自知识图谱的学习成分 (learning components)（learning-commons-kg.md，ELA 调用 2），点名具体的子技能；预备知识（先前标准的代码 + 要点 + 1 句假定先备知识的说明）
3. **词汇与预设难点** — 2–3 个第二层目标词，附定义和文本语境；3 个针对该文本与任务的迷思概念，取自知识图谱或训练知识，每个格式为：*学生怎么做* / *为什么发生* / *教师动作*
4. **课程流程** — 阶段按上文的年级段；在每一个学生动手做的阶段（阅读、单词练习、写作、分类）中：3 条以上观察要点，每条点名具体的学生行为、它对标准为何重要、以及如何应对；在每一个讨论阶段：具体的文本依赖提示（不能是泛泛的）
5. **设计说明** — 最后一节，在出门票之后：改编时应保持完整的 2–3 个要素，每个附一句基于研究的理由（K–2 拼读依据阅读科学 (Science of Reading)；3–12 年级依据文本复杂度研究），包括本课的核心表征或例行环节及其一句话说明。

→ **章节结构完成。进入草案（当教师选择了草案时）或第 5 步。**

## 出门票设计指南

出门票是课程流程的最后一个阶段（在其阶段标题下以 `from_shared:exit_ticket` 引用）。一道题，针对标准要求的最难的推理或应用。K–2 拼读：读词 + 拼词。K–2 理解：口头或简单书面检查。3–12 年级：需要证据的文本依赖问题；6–12 年级也可以改用回看导入快速写作的自我评估。三个分拣桶（掌握了 / 差不多了 / 需要重教）。

## 编写 lesson.json — ELA 映射

当你执行到 SKILL.md 的第 5 步（输出）时，在 `shared` 中登记 ELA 内容并像这样组织
`documents[]`：

- `shared.subject`：`"ELA"`。
- 锚文本或共享写作提示作为 `shared.anchor_task`：
  `{teacher: <如何介绍/朗读它>, student: <学生读到的任务，若导入纯口头则为 null>}`。
- 锚文本本身（如被重印）单独成键——如 `shared.passage`：
  `{type: "source_card", title, author, excerpt}`。如果文本由教师提供或
  受版权保护，不要重印——教案在材料清单和使用它的阶段中点名它
  （标题、作者、出处）。
- 每个文本依赖问题 / 写作任务作为 `shared.q1`..`qN`：
  `{student: <题目>, teacher?: <优秀回答会引用什么>}`。
- `shared.exit_ticket`：`{student: <题目>, teacher?: <收集说明>}`。分拣
  标准是一个 `cards` 块，在教案中拉入出门票之后放置
  （见 `example_lesson.json`）。
- `shared.vocabulary`、`shared.misconceptions`、`shared.look_fors` 按 `references/output.md` 的模式处理。

**要输出哪些文档。** K–2 音素意识或口语课（RF.*.2、
RF.*.3 拼读热身、听力理解）常常**没有 `student_materials`
文档**——学生手持应答卡或什么都不拿。要在教案的材料
行和你给教师的消息中说明这一点。3–12 年级的读写课要输出
`student_materials`；如果锚文本被重印，再输出一个 `source_packet` 文档，
只含 `from_shared:passage`。

**学生页布局**（如输出）——从这里出发按需调整：

```
sections:
  "Before you read"        from_shared:anchor_task ; answer_box if a written prediction
  "Text"                   from_shared:passage   (omit when the text isn't reproduced)
  "Read and respond"       for each question k:
                             group[ {type: from_shared, key: qk, label: "k"},
                                    answer_box ]
                           page_break
  "<exit heading, kid-facing>"     group[ from_shared:exit_ticket, answer_box ]
```

**课堂观察模板布局**与 `references/math.md` 中的数学布局一致。
