# 社会学科 — 分层教学法

当学科为**社会学科**时由 `k12-lesson-differentiation` 加载。

## 识别源课程

**州识别。** 社会学科标准是州专属的。如果教师点名了州（或对话
前文中已确定州），锚定到该州：使用州专属标准框架（例如
加州 HSS 框架、得州 TEKS、纽约 Passport to Social Studies）作为主要
内容范围参照。如果教师没有点名州且无法推断，询问。

**C3 框架说明。** C3 框架是一个*探究设计*框架，不是标准文件。用 C3
的教学设计原则（探究弧、史料溯源、论证、公民行动），但学生必须
知道和会做什么以州标准为准。如果教师直接提到 C3，用它的
探究弧来组织课程任务——但内容范围锚定在州标准上。

然后识别适用哪个场景：

**场景 A — 源课程存在于之前的对话中**
如果本对话前文中已经生成或讨论过一节课，直接使用它。不要重复要求教师分享。

**场景 B — 教师上传源课程**
先读文件。确认：年级、学科（历史 / 公民 / 地理 / 经济）、
标准、学习目标、课程结构。**同时从标准代码中提取州**
（TEKS 113.xx → 得州；加州 HSS/CCSS → 加州；MA 课程
框架 → 马萨诸塞州；等等）。记为 state——如果能从标准代码
推断，就不要问教师。

**场景 B2 — 教师用 URL 链接源课程**
先抓取 URL 并阅读其内容。然后与场景 B 完全一样地确认年级、
学科（历史 / 公民 / 地理 / 经济）、标准、学习目标和课程结构。
如果抓取失败或返回不可用内容，清楚地说明错误并请教师
粘贴课程文本或上传文件。绝不静默编造一节课。

**抓取课程只完成第 1 步——它不替代标准锚定。** 继续执行第 2 步——锚定标准。URL 抓取之后跳过第 2 步，与上传课程后跳过它一样属于严重失误。

**场景 C — 没有源课程**
继续之前询问（如果州也未知，一并问州）：
> "很乐意帮你做分层。你心里有具体的一节课吗？你可以粘贴过来、分享文件，或者告诉我年级 + 主题 + 标准，我据此来做。"

## 分层规则

把全部八条规则应用到每一节分层课程。

### R1 — 输出结构

**1 份完整连贯的面向教师分层教案 + 3 份纯粹的学生练习页。绝不产出 3 份按水平混合编排的教案。**

混合模式——3 份按水平各自混杂教师注释和学生内容的文档——
是一种具体的失败模式。教师教案在一份文档中覆盖所有水平；
练习页只含学生内容。

### R2 — 标准范围保全

**每个层级都针对原标准。标准的每个要素在所有层级中都保留——包括难题情形。**

标准中认知要求最高的部分恰恰是低水平学生最需要在支架支持下
遇到的东西，而不是要被砍掉的要素。常见失败模式：
- ❌ 为低水平学生把互证任务（比较两份史料）换成单份史料
  任务——这不是分层，只是换了个作业。
- ❌ 把核心问题从低水平学生的任务中移除。
- ❌ 为低水平学生把论证换成识别。

**Below 层级的参与度必须保全。** 不要把丰富的一手史料或
引人入胜的核心问题分给 At/Above，把练习单操练分给 Below。
所有层级探究同一个核心问题和同一史料情境——只是支持不同，
不是任务不同。

### R3 — 通过预备知识向上教学

**低水平支架把学生向上引导到年级水平的学习，锚定在社会学科的两个默认预备知识上。不是"只是更容易"。**

- ✓ "低于水平组用引导式批注框架 (SOAPS) 为史料溯源流程搭支架；学生把它应用到同一个年级水平的史料任务上。"
- ✗ "低于水平组用更短的文本 / 更简单的词汇 / 更少的史料。"

**社会学科的两个预备知识。** 与数学不同，知识图谱不为社会学科
标准提供明确的预备知识映射。几乎适用于每一节社会学科课的
两个预备知识是稳定的默认值：

1. **内容词汇。** 进入本课史料和任务所需的具体术语是首要
   门槛。从本课的史料本身提取 4–6 个关键词——它们构成词库。
   词汇是一个预备性门槛，不只是 UDL 特征；尽管 R8 也要求
   把它作为所有层级的 UDL 默认值，它仍归属于这里。

2. **作为已教流程的史料溯源。** 史料溯源（这是谁写的、为什么写、
   在什么条件下写的？）是基础性的学科技能——是语境化和
   互证的预备条件。把它当作一个*已教流程*来对待，而不是
   假定学生已具备的能力。学科思维技能不遵循严格的年级
   进阶；问题在于这个流程是否被明确教过，而不是哪个年级
   引入的。除非教师确认史料溯源已是班上的既定做法，否则
   默认用引导式批注框架（SOAPS 或 HAPP）作为主要的低水平支架。

当教师确认史料溯源已是既定做法时，把低水平支架转向语境化
支持。当本课的目标是互证时，把史料溯源 + 语境化当作
预备基线，从那里往上搭。

#### 史料复杂度切入点

| 层级 | 切入点 |
|---|---|
| Below | 具象 / 视觉——照片、地图、实物，或带大量注释的短节选；1 份史料；有支架的分析框架 |
| At | 表征 / 文本——分级文本或带轻度注释的一手史料；1–2 份史料；结构化问题 |
| Above | 抽象 / 论证——完整的一手史料或复杂的二手文本；2–3 份史料；开放综合或论证任务 |

### R4 — 低水平支架

**目标是保留有生产力的挣扎，而不是消除它——支架支持思考，
不泄露答案，也不把标准要求的历史/公民推理压扁。**

要避免的失败模式：

- ❌ 单因简化：为低水平学生把复杂的历史成因压缩成一个
  因素。过度简化不是支架——它破坏标准所要求的学科思维。
- ❌ 答案内嵌的问题：把问题设计成让历史解释在问题本身中
  就已揭示。
- ❌ 填空式叙述，学生只填入预先给好的事实。
- ❌ 以今度古 (Presentism) 的框架：不给历史语境搭支架，却用现代
  价值观来简化历史情境。
- ❌ 在标准要求开放分析或论证时用选择题考史料溯源。

可接受的支架：

- ✓ 历史/公民分析的句子支架："这份史料表明 ___，因为 ___。这很重要，因为 ___。"
- ✓ 引导式批注框架（如 SOAPS：来源 (Source)、场合 (Occasion)、读者 (Audience)、目的 (Purpose)、主题 (Subject)；或 HAPP：历史语境 (Historical context)、读者 (Audience)、目的 (Purpose)、观点 (Point of view)）——预结构化的提示，而不是预填的答案。
- ✓ 分级文本：同一主题、同一核心问题，不同阅读复杂度。所有层级回答同样的问题。
- ✓ 视觉一手史料（照片、地图、政治漫画）作为具象切入点，之后再过渡到文本类史料。
- ✓ 学科词汇词库（用于词汇，而不是用于选择论证或答案）。注意：按 R8 的 UDL 要求，词库默认出现在所有层级——不要只限 Below。
- ✓ 与思维类型匹配的图形组织图（见下表）。
- ✓ 减少史料数量，但带明确的迁移步骤："先分析这一份史料，然后把同样的思考应用到第二份上。"

#### 概念 → 主要支架

| 社会学科思维类型 | 主要支架 |
|---|---|
| 时序推理 / 排序 | 带注释的时间线或因果链组织图 |
| 一手史料分析 | 引导式批注框架（SOAPS 或 HAPP） |
| 地理 / 空间推理 | 带结构化引导问题的标注地图 |
| 公民论证 / 基于主张的推理 | CER（主张—证据—推理）框架 |
| 经济决策 / 权衡 | 成本—收益或稀缺性组织图 |
| 多重视角 / 观点 | 双栏视角组织图 |
| 比较 / 综合 | T 形图或证据综合矩阵 |

根据学科思维类型而不是年级选择**主要支架**。如果思维类型
横跨多个类别，为低水平学生更吃力的那个动作选支架。

检验标准：支架是把学科思维留给学生，还是替学生完成了
那种思维？如果是后者，它就不是支架。

#### 支架密度上限

**嵌入支架上限为每个任务 1–2 个。不得超过。**

| 类型 | 是否计入上限？ |
|---|:-:|
| 嵌入式——直接印在任务上（组织图、句子支架、批注提示） | 是 |
| 页眉级特征——词汇框、练习页顶部的句子支架 | 否 |
| 教师侧工具——按需提供的分级文本、个别指导话术 | 否 |

**先选一个主支架。** 只有当第二个支架贡献了真正不同的模式时
才加。如果第二个要求学生做同样的认知工作，删掉它。

### R5 — 必需的教学基础设施

**每节分层课程必须包含全部四项：**

| 部分 | 是什么 | 位置 |
|---|---|---|
| **形成性检查** | 具体的课中或课尾检查准备度的提示——分层出门票即可。不是"巡视学生"。 | 教师教案 + 各水平练习页 |
| **锚活动** | 给先完成学生的对齐标准的任务——例如再分析一份史料、一个"那又怎样？"的拓展问题，或与当前时事的联系。不是打发时间的杂活。以面向学生的写法写进 `shared.anchor_activity` 并印在每份练习页上——只作为教案描述存在的锚活动属于失败。 | 教师教案 + 全部三份练习页 |
| **弹性分组用语** | 层级归属与本课的证据挂钩，明确可根据形成性检查的发现修订。不是固定的能力轨道。 | 教师教案 |
| **分水平的迷思概念注释** | 各水平特有的学科常见错误 + 教师提示 + 小组辅导信号。有知识图谱来源时优先使用，否则自行起草。 | 教师教案 |

此外：**每份学生练习页都以一个开放式或反思性提示收尾，三个层级
都有**——例如"这份史料让你产生了什么问题？"、"这些史料中缺少了
谁的视角？"、"这与今天发生的什么事有联系？"这对任何层级都
不可省略。把它存为 `shared.reflect_prompt`，并在教师教案中每个层级的
**练习页任务**一行中点名它——教案从未提及的已打印任务属于失败。

### R6 — 隐形调整

**在教学法允许的前提下，各层级同一核心问题 / 同一史料情境 / 同一核心任务。只有支持不同。**

可以不同的：所提供文本的阅读复杂度；练习页上的支架；
个别指导时可选的教师支持；拓展或反思提示。

不应不同的：正在探究的核心问题；所要求的学科思维类型
（不要为低水平学生降低思维类型）；所研究的历史/地理/公民
现象。

**不要向学生宣布支架的撤除。** 如果任务 1 有支架而任务 3 没有，
它的缺席是静默的——不加标签、旁白或评论（例如不写
"（这次没有批注框架）"或"试试不用组织图来做"）。支架只是不出现；
学生按任务本来的样子面对它。

默认各层级使用同样的一手史料。只有 Below 层级可以调整
史料复杂度（例如用带注释的节选代替完整文献），且必须
完整保留核心分析任务。

### R7 — 层级内渐进撤除支架

**每个水平的练习页按渐进认知要求编排任务顺序。**

#### 低水平支架撤除模式

| 任务 | 嵌入支架 | 模式 |
|---|:-:|---|
| 任务 1 | 至多 2 个 | 有支架 |
| 任务 2 | 至多 1 个 | 有引导 |
| 任务 3 及以后 | 0 个嵌入式 | 独立 |
| 出门票 | 0–1 个 | 掌握度检查 |

目标是真正的撤除（2 → 1 → 0），而不是均匀密集任务上的
表面差异。

#### 高水平拓展质量检验

每个高水平拓展都必须回答：**它要求了什么达到水平的学生
没有在做的新学科思维？**

一个真正的拓展至少要求以下之一：

| 类型 | 它要求什么 |
|---|---|
| 新的认知操作 | 达到水平在溯源/描述；超出水平在互证、评价或构建论证。（布鲁姆 / Webb DOK 层级上移。） |
| 史学或学科洞见 | 呈现学术争论、解释张力或方法论问题——不只是"发生了什么"，还有"我们如何知道"。 |
| 后续标准预览 | 来自进阶后续标准的真实分析要求——不只是它的词汇。 |
| 开放生成任务 | 学生产出新东西：历史论证、反驳、公民提案、带主张的地图。 |

以下情况驳回：只是覆盖同一论证的更多史料、只是换记号或
词汇，或只是换个说法。

### R8 — 范围与默认值

**如果未指定层级范围，生成之前问一个合并问题：**

> "我会把这节课分成低于 / 达到 / 超出年级水平三个层级——分这三个
> 合适吗？还有没有什么我该知道的具体学习者需求（ELL 学生、
> IEP 安排、阅读水平）？如果没有，我会应用 UDL 默认值
> （所有层级都有句子起始句和词汇支持）。"

如果范围已被指定，静默采用默认值并继续。

**未指定时静默采用的默认值：**
- 层级：低于 / 达到 / 超出
- UDL 特征：**全部三份**学生练习页都有句子起始句和词汇表
  （不只 Below——量规 O5）
- 范围：完整课程（所有阶段 + 出门票）
- 层级数：3
- **层级画像（无 FA 数据时）：** Below——很可能有内容词汇缺口；
  史料溯源流程尚未内化；用引导式批注框架 + 词库搭支架。
  At——核心词汇基本就位；在提示下能运用溯源和语境化。
  Above——能独立处理年级水平文本；能较独立地运用溯源和
  语境化；可以做互证或多史料任务。
- **FA 追问提示。** 生成默认分层教案之后询问：*"你最近有没有
  关于学生水平的信号——词汇检查、之前的溯源任务，或出门票
  结果？"* 社会学科的 FA 数据主要帮助确认两个默认障碍
  （词汇 vs 史料溯源流程）中该更侧重哪个——它很少完全改变
  支架类型。把它当作有用的 refinement，而不是必需输入。

### 文档内容 — 教师教案（`id: teacher_plan`）——最多 3 页

**篇幅预算：渲染后约 1,200 词（即 3 页上限的实际含义）。** 先收紧层级
部分和概览，再动收尾部分（弹性分组、设计依据、后续
步骤）——最常见的超支是练习页任务行复述了练习页内容
而不是点名它。**"设计依据 (1)"和"设计依据 (2)"是必需的，
不能为了满足篇幅预算而删掉——先削减层级部分的文字。**

下方大纲定义教师教案文档 `sections` 的内容与顺序：
每个 `##` 标题成为一个章节，其正文成为该章节的内容块
（标准、迷思概念和出门票用 `from_shared` 块；粗体字段用
`labeled` 块）。

```markdown

## Learning Objective
[Same objective across all tiers — preserved from source lesson]

## Differentiation Overview
[1 short paragraph, ≤3 sentences: approach, source complexity entry point, primary scaffold
type, essential question preserved across tiers. Standards by code + ≤10-word gist — the
target standard is already verbatim in the header.]

[ONE `table` block — never three labeled paragraph stacks. Columns: Below (Group A) / At (Group B) / Above (Group C).

  routine status (scaffolded via [annotation frame type] or established). Above: forward
  standard by code + ≤10-word gist from [state] vertical alignment. At: "—".
- **Scaffolds / extension** — fragments, ≤25 words per cell: Below scaffolds in play; At
```
