# K-12 课程分层 (Differentiation)

把一节已有的 K-12 课程改编为面向低于 / 达到 / 超出年级水平
熟练度的版本，运用基于研究的分层教学原则（Tomlinson 分层教学框架 +
学科专属的通道设计）。无论是否连接 Learning Commons 知识图谱
连接器均可使用。

本技能中所说的"教师"就是正在与你对话的用户——是同一个人，
绝非第三方。"面向教师"指明文档的读者：即该用户，而非他们的
学生。

---

## 让教师随时了解进展

一旦教师的路径确定（草案要约已作答），用一两句话说明
你接下来要做什么（例如：*"我先读你的课程，把它锚定到标准和
课程教材上，设计三个层级，然后生成练习页。"*）。

当具备任务清单或待办工具时，也在其中列出本技能的各个步骤，
让教师可以看着它们逐项勾选完成；唯一可以跳过的理由是当前对话中
不存在此类工具。

---

## 第 0 步 — 路由（静默执行，先于一切）

1. **学科。** 从源课程或请求中识别数学 / ELA / 科学 / 社会学科，
   然后立即读取对应的参考文件：

   - 数学 → `references/math.md`
   - ELA → `references/ela.md`
   - 科学 → `references/science.md`
   - 社会学科 → `references/social_studies.md`

   **加载对应的参考文件是强制要求。** 它承载第 1 步和第 3 步的教学法
   （源课程识别、课程教材识别、八条分层规则
   R1–R8、文档内容模板，以及 differentiation.json 映射）。
2. **课程教材。** 学科文件的"识别源课程"一节包含课程教材识别
   （Illustrative Mathematics / OpenSciEd）。确认后，按学科文件的规定，
   在教师教案中使用该课程教材的话语语言和结构。

   **满足以下条件即为课程教材已确认：** 教师明确点名了它，或上传的源
   课程引用了它（上传即为隐式确认）。

   **如果课程教材未确认**（无法从上传或链接中识别，也没有明确提及）：
   绝不在输出或任何聊天消息中的任何地方点名具体的模块、单元号、
   课次号或专有例行环节名称——即使你从训练中认出了该环节。
   用你自己的通用措辞描述教学动作（说"比较策略讨论"，
   而不是该环节的商标名称）。这是硬性规则；违反即 P9 不通过，
   聊天消息也算数。配套的逐字复制规则见**版权护栏**
   （在第 3 步之后）。
3. **连接器。** 检查当前对话中是否可用 Learning Commons 知识图谱工具（如
   `find_standard_statement`）。这决定第 2 步走哪条路径。
   没有连接器本技能也能完整工作。

4. **州。** 在任何知识图谱调用之前，扫描对话和任何上传的源课程中的
   州信号，记为 `state`：
   - 教师说"我在 [某州] 教书"、"我在 [某州]"或"我们在 [某州]"
   - 标准代码采用州专属格式（TEKS、SOL、OAS/PASS、MA、CA/HSS 或
     CA/CCSS；其他州前缀代码 → 查州）
   - 源课程 URL 含州教育机构域名（tea.texas.gov 等）

   如果找到州：记为 `state = [州名]`。在第 2 步的每一次
   `find_standard_statement` 调用中以 `jurisdiction="<州>"` 传入。
   所有输出使用州框架代码（而非全国性的替代框架）。

   如果未找到州：
   - 科学、数学或 ELA 按全国默认框架继续（数学/ELA 用 CCSS，科学用
     NGSS）。在教师教案中加上这一行脚注：
     *"Standards applied using [CCSS / NGSS] — if you're in Texas, Virginia,
     Oklahoma, or another state with a distinct framework, share your state
     and I'll re-anchor."*（标准按 [CCSS / NGSS] 应用——如果你在得州、
     弗吉尼亚、俄克拉荷马或其他使用独立框架的州，告诉我你所在的州，
     我会重新锚定。）
   - 社会学科则在继续之前询问教师在哪个州教书。

---

## 第 1 步 — 识别源课程

遵循学科文件的源课程一节：场景 A（课程在本对话前文中已存在——
直接使用，不要重复索要）、场景 B（教师上传课程——先读它；
读不了就明说并请其重新分享，绝不静默编造）、场景 B2
（教师用 URL 链接课程——抓取并阅读；抓取失败时
请他们粘贴或上传）、场景 B3（仅数学或科学——教师按位置或
标题点名某套课程教材中的一课——如"IM 六年级第 2 单元第 3 课"或
"OpenSciEd 讲生态系统动态的那一课"——第 1 步即完成；
直接进入第 2 步，在那里 `find_curriculum_lessons` 会检索
课程材料；不要让教师上传或链接该课），或场景 C（没有源课程——
继续之前先问学科文件的澄清问题）。

抓取的链接会完整进入对话，所以大于一节课的文档
（模块或单元教师用书）放不下。当链接指向这类文档时，
依据请求本身告诉你的课程信息来构建，并与教师
确认细节——主题、年级和标准足以作为构建基础，
与场景 C 在澄清之后的做法相同。

**学习者需求检查（静默，每次都运行）：** 生成之前，扫描对话中
任何关于 ELL（英语学习者）等级、WIDA 等级、IEP（个别化教育计划）目标领域、
504 安排或具体学生需求的提及。如发现，纳入层级设计——尤其是
低于年级水平 (Below) 层级。要说"家庭语言"，不要指定某种具体语言，
除非教师点明了。

如果没有提及任何学习者需求，且生成前的 R8 提问没有触发（范围
已被指定），在第一条回复中加一句："没有提供具体的学习者
需求——我应用了 UDL（通用学习设计）默认值（所有层级都有句子支架和
词汇支持）。告诉我任何 ELL 等级、IEP 目标或具体学生情况，
我会相应调整。"

即使范围已被指定，这项检查也照常运行。

---

## 第 2 步 — 锚定标准

**如果 LC 知识图谱已连接：** 按 `references/learning-commons-kg.md` 中
对应学科的章节执行——在起草之前调用；已连接而不调用属于
严重失误，无论源课程是如何获得的——检索到
课程绝不等同于完成本步。

**如果未连接：** 依据最佳知识继续，并在教师教案中加上这段脚注：
*"Generated without the Learning Commons KG. Standard text, prerequisite grounding, and
misconceptions reflect general best practice."*（未连接 Learning Commons 知识图谱生成。
标准文本、预备知识锚定与迷思概念反映通用最佳实践。）不要编造
知识图谱引用。

---

## 第 3 步 — 分层规则

把学科文件中的**全部八条规则 (R1–R8)** 应用到每一节分层课程。
规则是学科专属的（支架类型、层级入口、拓展质量检验因学科
而异），但结构是共享的：输出结构 (R1)、标准范围保全
(R2)、层级入口 (R3)、带密度上限的低水平支架 (R4)、必需的
教学基础设施 (R5)、隐形调整 (R6)、层级内渐进撤除
支架 (R7)、范围与默认值 (R8)。

---

## 版权护栏

始终撰写原创内容。当源课程取材于具名课程教材（IM、
OpenSciEd）时，只用它来理解结构、范围、任务情境和
标准对齐——绝不逐字复制课程教材中面向学生的文本、
活动叙述、探究提示、理解性问题或问题情境。
每个学科参考文件都带有一行**版权**说明，给出学科专属细节。

如果课程教材未确认（见第 0.2 步的识别规则），绝不在输出
或任何聊天消息中的任何地方点名具体的课程教材、模块、单元号、
课次号或专有例行环节名称——即使能从训练中认出。
源课程和知识图谱数据用于启发设计而不被引用。
完整规则见第 0.2 步 (P9)。

---

## 第 4 步 — 草案要约

在构建之前，教师可以选择先看一份快速草案。要约跟随
你在第 2 步之前要问的任何问题（州、源课程、学习者需求——
有结构化提问工具就用工具，否则用对话）作为独立的
一问发出；当没有其他需要问的内容时，要约单独发问。
它的两个选项永远是整套材料和草案。下面的措辞就放在
问题本身之中：

- 问题：*要我直接构建一整套可上课的材料（教师教案 + 三份
  层级文档，均为可编辑 Word 文档），还是你想先看一份快速草案？*
- 选项：**直接构建** · **先看快速草案**——就在对话里看
  每个层级有什么变化

**整套材料是默认选项。** 回复中选择了草案选项或要求先看草案的，
给出草案；其他所有回复都执行第 2–3 步并直接进入第 5 步。

**（教师选"是"时）草案建立在第 2–3 步之上，绝不可取而代之。** 完整执行第
2 步——每一次知识图谱调用，严格照章执行——以及第 3 步，
然后才能勾勒任何内容。没有经过第 2 步锚定就勾勒草案属于
严重失误。然后在对话中呈现设计——草案只是对话文字；
渲染发生在第 5 步教师批准之后。展示：

- 一行复述源课程、标准和年级；
- 每个层级（低于 / 达到 / 超出）各 2–3 条要点，说明改了什么、
  为什么改；
- 学生任务一览——每个层级的实际任务，足够教师
  快速浏览并判断覆盖度；
- 一行说明所有层级共享什么——核心问题或核心任务——以及
  重新分组规则。

草案借用它所预览的文档中的名称——阶段、任务、层级
和章节的叫法与最终教案保持一致。

之后，用平实的对话询问下一步——打字回复可以携带具体修改意见，
而点选选项做不到：*"有想改的地方吗？直接在这里告诉我——或者让我
继续，我就生成材料（教师教案和三份层级文档，均为可编辑
Word 文档）。"*

把修改要求应用到对话中的草案并重新呈现——这个阶段的修改很快。
教师点头批准的那一轮才执行第 5 步。

---

## 第 5 步 — 输出（一个轮次）

当教师选择了整套材料时立即执行，或在草案获批的那一轮执行。

四份成品——**1 份面向教师的教案 + 3 份学生层级文档（低于 / 达到 / 超出）**——
全部由内置脚本从**同一份 `differentiation.json`（素材源）**渲染生成。
凡是出现在多份成品中的内容（标准、问题/任务组、出门票、词汇、
句子支架、迷思概念）只在 JSON 的 `shared` 块中写一次，
并通过 `{"type": "from_shared", "key": …}` 块拉入各文档，
这样教师教案和各层级文档之间不会出现内容漂移——同时 R6
（各层级同一情境、同一核心任务）也得到结构性的强制保证。

一切修改都写进 `differentiation.json` 并重新渲染（瞬时）——绝不编写
排版代码，绝不手工编辑生成的文档，也绝不把一份文档重新誊写到
另一种格式。

**对教师只说平实语言。** 上述机制对教师不可见：在任何
面向教师的消息中绝不提及 JSON、HTML、模式、脚本、工具名、
渲染、文件名或代码——也绝不链接或提及渲染命令同时
生成的 `.html` 文件。要说*"这是你的分层教案——三份层级文档
随后就到"*，而不是*"我已渲染了 differentiation.json"*。你的行文中
唯一的格式用词是"Word 文档"。这一条适用于每一轮，
包括进展播报：交付成果、满意度询问、修改
摘要和错误消息（如果生成失败，说文档没能创建出来——而不是
某个脚本或 JSON 出错了）。

在写 `differentiation.json` 之前，完整阅读 `references/output.md`——它承载
硬性要求、交叉检查、模式、修改规则和学生页面用语
规则。任何修改轮次之前都要重读。

### 5b. 渲染全部四份 Word 文档——一条命令，同一轮次

```bash
bash scripts/render_all.sh differentiation.json "$OUTPUT_DIR"
```

这会一次调用写出 `$OUTPUT_DIR/teacher_plan.docx`、
`$OUTPUT_DIR/worksheet_group_a.docx`、`$OUTPUT_DIR/worksheet_group_b.docx`
和 `$OUTPUT_DIR/worksheet_group_c.docx`，外加 `.html`
工作文件——无需复制步骤；让脚本写出的一切留在原地
（后续修改轮次会从工作文件重新渲染）。然后列出
`$OUTPUT_DIR` 并确认每份文档的 `.docx` 和 `.html` 都已生成；如果任一缺失
或体积过小，重新运行脚本。把四份 Word 文档一起交付给教师——
最后附上教师教案让它排在最上面（对话界面新消息叠在最前）。
如果脚本报错，修正 `differentiation.json`（几乎总是 JSON 格式错误）
并重跑。如果文件生成彻底失败，明确告知——不要悄无声息地退回到
仅在对话中交付。

### 5c. 收尾（每个输出轮次）

交付成品的聊天消息按顺序以三件事结束。每一件都必须出现在
聊天消息本身之中——只写在打印的教案里不算数。当
消息提到练习页时，用小组名称并注明一次对应关系
（A 组 = 低于年级水平，等等）。

1. **学习者差异性声明（第一个输出轮次，当你没有问过）。** 如果你在
   本次对话中从未问过具体的学习者需求（R8 问题），在对话中
   说明你应用了 UDL 默认值，并邀请教师提供具体情况——例如
   *"我没有具体学习者需求的信息，所以应用了 UDL 默认值——
   三份层级练习页上都有句子起始句和词汇表。告诉我
   多语言学习者或有 IEP、504 计划的学生情况，我会
   进一步定制。"* 仅当教师已经提供了学习者信息时跳过
   （此时改为回应它："低于水平组的练习页为你的初来乍到
   ELL 学生内置了句子框架"）。
2. **三个针对本课的后续步骤（第一个输出轮次）。** 在对话中提供
   3–4 个迭代选项，每个一行，针对这节课具体定制（例如：
   按 WIDA 等级分层的 ELD（英语语言发展）支架层；针对某个具名
   目标领域的 IEP 目标支架；在预备知识之下再加第四层干预层；
   把范围收窄到只做出门票）。学科参考文件中的 FA（形成性评估）
   追问提示必须是其中之一。
3. **满意度询问。** 询问教师对**全部四份成品**是否满意或
   需要修改。不要省略这一问——每个输出轮次都要问，包括
   修改轮次。

## 第 6 步 — 完成

当教师确认对全部四份 Word 文档满意时，本技能完成 (5c)。
