# TEXTBOOK_NAME 的学习图谱

本 section 包含本教材的学习图谱。学习图谱是
本教材所用概念的图。每个概念由
网络图中的一个节点表示。概念之间由有向边连接，表明
学生在理解某个概念之前，该节点依赖于哪些概念。

学习图谱是智能教材的基础数据结构，智能教材可以据此推荐学习路径。
学习图谱就像一张概念路线图，帮助学生抵达学习目标。

学习图谱的最左侧是先修或基础概念。它们
没有出向边，只有入向边——来自其他依赖
对这些基础性先修概念的理解的概念。在最右侧
是课程中最高阶的概念。要掌握这些概念，你
必须理解它们所指向的所有概念。

下面是学习图谱用到的其他文件。

## 课程描述

我们以[课程描述](../course-description.md)作为
本课程所含概念的来源文档。
课程描述使用 2001 版布鲁姆分类法来组织学习目标。

## 概念清单

我们使用生成式 AI 把课程描述转化为[概念清单](./concept-list.md)。
每个概念都是简短的标题式大写（Title Case）标签，大多数标签不超过 32 个字符。

## 概念依赖表

接下来我们使用生成式 AI 创建一个有向无环图（Directed Acyclic Graph，DAG）。DAG 中没有
概念自我依赖的环。我们以两种格式提供 DAG。一种是 [CSV 文件](learning-graph.csv)，另一种
是使用 vis-network JavaScript 库格式的 [JSON 文件](learning-graph.json)。vis-network 格式使用 `nodes`、`edges` 和 `metadata`
元素，边中包含 `from` 和 `to` 属性。这样你就可以方便地使用
基于 vis-network 工具构建的编辑器查看和编辑学习图谱。

## 分析与文档

### 课程描述质量评估

本报告就「用于生成学习图谱」这一目标，对课程描述的总体质量进行评级。

- 课程描述字段与内容深度分析
- 校验课程描述是否有足够深度生成 300–600 个概念
- 将课程描述与同类课程比较
- 识别内容缺口与优势
- 提出改进建议

[查看课程描述质量评估](course-description-assessment.md)

### 学习图谱质量校验

本报告给出学习图谱质量的整体评估。
它使用图算法在图中寻找特定的质量模式。

- 图结构校验——所有概念均已连通
- DAG 校验（未检测到环）
- 基础概念：10 个入口点
- 入度分布分析
- 最长依赖链
- 连通性：连接到主集群的节点百分比

[查看学习图谱质量校验](quality-metrics.md)

### 概念分类法

为了看清学习图谱中的模式，按概念类型
为每个概念着色是很有用的。我们使用生成式 AI
为概念创建约十二个类别，然后把每个概念
归入单一的主要分类器。

- 约 12 个类别（±1 或 2）的概念分类器分类法
- 类别组织——基础元素在前，课程顶点项目设想在最后
- 均衡的类别（各占 3.5%–15%）
- 所有类别均低于 30% 阈值
- 教学流程建议
- 供 CSV 文件使用的清晰的 3–5 个字母缩写
- 有时会加入一个杂项（MOSC）类别

[查看概念分类法](concept-taxonomy.md)

### 分类法分布

本报告展示每个分类法类别各容纳了多少概念。

相近数量的概念。我们也不希望任何类别

- 统计分解
