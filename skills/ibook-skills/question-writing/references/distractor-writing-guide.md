# 干扰项写作指南（Distractor Writing Guide）

本参考文档为选择题测验中的高质量干扰项（错误答案选项）撰写提供详尽指南。

## 什么是好的干扰项？

好的干扰项服务于教学目的：它们测试理解、揭示常见误解，而不只是凑数的选项。

### 有效干扰项的四个品质

1. **可信性（Plausibility）**——对尚未掌握内容的人来说显得合理
2. **教学价值（Educational Value）**——测试理解或揭示误解
3. **区分度（Discrimination）**——帮助区分不同的知识水平
4. **公平性（Fairness）**——不是脑筋急转弯或不公平的陷阱

## 可信性

### 定义

可信的干扰项，在没有完全学会该材料的人看来像是正确的，但在已掌握的人看来明显是错的。

### 构造可信干扰项的技巧

**1. 使用相关术语**

❌ **不可信：**
题目：「什么是学习图谱？」
- A) 由习得行为构成的图
- B) 显示概念依赖关系的有向图 ✓
- C) 一根香蕉
- D) 字母表

✓ **可信：**
- A) 显示学生成绩随时间变化的图
- B) 显示概念依赖关系的有向图 ✓
- C) 教育目标的分类法
- D) 课程成绩的可视化表示

**2. 长度与结构相近**

所有选项的长度应大致相同，避免泄露「最长的答案就是对的」这一破绽。

❌ **不可信（长度露馅）：**
- A) 是 ✓
- B) 否
- C) 视具体情况而定，取决于特定的上下文因素与先修条件
- D) 也许

✓ **可信（长度均衡）：**
- A) 当所有先修条件都满足时 ✓
- B) 当教师批准时
- C) 当学生提出请求时
- D) 当学期开始时

**3. 语法一致**

所有选项都应能在语法上与题干衔接。

❌ **不可信（语法不匹配）：**
题目：「学习图谱最恰当的描述是……」
- A) 映射先修关系 ✓
- B) 正在展示关系
- C) 来组织
- D) 视觉的

✓ **可信（语法平行）：**
题目：「学习图谱最恰当的描述是……」
- A) 一种映射先修关系的结构 ✓
- B) 一种可视化进度的工具
- C) 一个组织内容的系统
- D) 一个排定主题顺序的框架

## 教学价值

### 定义

有教学价值的干扰项针对常见误解、测试相关概念，或有助于区分理解程度。

### 常见误解模式

**1. 部分真实（在别的语境下正确）**

这类干扰项本身是对的，但回答不了所问的特定问题。

示例：
题目：「学习图谱的**首要**目的是什么？」
- A) 为演示文稿制作视觉素材
- B) 映射先修关系 ✓
- C) 评估学生表现
- D) 组织课程材料

分析：A、C、D 可能是学习类工具的益处或用途，但 B 才是首要目的。

**2. 反向倒置（相反或颠倒）**

这类干扰项把正确的关系或概念倒过来。

示例：
题目：「在学习图谱中，从概念 A 指向概念 B 的箭头表示……」
- A) 概念 A 必须先于概念 B 学习 ✓
- B) 概念 B 必须先于概念 A 学习
- C) 概念 A 和 B 互不相关
- D) 概念 A 和 B 等价

分析：B 是正确答案的反面，测试学生是否理解依赖的方向。

**3. 相似术语（相关但不同）**

使用学生可能混淆的相关概念术语。

示例：
题目：「什么结构可以防止学习图谱出现环？」
- A) 链表
- B) 有向无环图 ✓
- C) 有向环图
- D) 无向图

分析：C 与 B 非常相似，但有本质区别（有环 vs. 无环）。

**4. 常见学生错误**

基于学生的典型误解或失误。

示例：
题目：「脚手架（scaffolding）应该在什么时候撤除？」
- A) 在教学开始时
- B) 随着能力提升逐步撤除 ✓
- C) 永不撤除，应永久保留
- D) 引入之后立即撤除

分析：A 和 D 反映了一种常见误解——脚手架撤得太快。C 反映了相反的错误。

## 区分度

### 定义

有区分度的干扰项能帮助识别学生的不同理解水平：从完全不懂，到部分理解，再到掌握。

### 干扰项区分度的层次

**不懂 → 部分理解 → 掌握**

构造能分别吸引不同知识水平的干扰项：

**示例：**

题目：「符合 ISO 11179 对术语表定义的要求是什么？」

- A) 定义必须按字母顺序排列（不懂——把组织方式当成了质量要求）
- B) 定义必须又长又详细（部分理解——知道定义需要细节，但不知道具体要求）
- C) 定义必须精确、简洁、互不相同且不循环 ✓（掌握——知道这四条准则）
- D) 定义必须包含示例（部分理解——知道示例有帮助，但把它与要求混淆了）

**考查的知识水平：**
- **A** 吸引完全不了解 ISO 11179 的人
- **B** 和 **D** 吸引只有部分理解的人
- **C** 需要掌握具体的准则

## 公平性

### 定义

公平的干扰项考查的是学科知识，而不是应试技巧、阅读理解或琐碎细节。

### 应避免的不公平干扰项模式

**1. 脑筋急转弯**

❌ **不公平：**
题目：「学习图谱**最好**的数据结构是什么？」
- A) 有向无环图 ✓
- B) 有向无环图

分析：给出两个一模一样的选项是陷阱，不是知识考查。

**2. 文字陷阱**

❌ **不公平：**
题目：「以下哪一项不是不重要的？」
- A) 先修知识
- B) 依赖关系 ✓
- C) 脚手架
- D) 示例

分析：双重否定让题目费解，考的是阅读理解而不是知识。

**3.「以上皆是」/「以上皆非」**

❌ **避免：**
- A) 学习图谱
- B) 概念依赖
- C) 脚手架
- D) 以上皆是

为什么避免：把题目降格成二选一（全是 vs. 不全是），而不是考查具体知识。

**例外：** 如果确实有教学价值可以使用，但总体上应避免。

**4. 过于冷僻或琐碎的细节**

❌ **不公平：**
题目：「学习图谱的定义在教材的第几页？」
- A) 第 42 页
- B) 第 45 页 ✓
- C) 第 48 页
- D) 第 51 页

分析：考的是对琐碎细节的死记硬背，不是理解。

**5. 绝对化用词**

❌ **太明显：**
- A) 学习图谱**总是**能解决所有教育问题
- B) 学习图谱**从不**出现任何问题
- C) 学习图谱可以帮助组织概念依赖 ✓
- D) 学习图谱**完全**没有必要

分析：「总是」「从不」「完全」暴露了这些选项明显错误。

## 干扰项构造模式

### 模式 1：相关概念

使用同一领域中学生可能混淆的概念。

**示例（教育技术）：**
题目：「什么是 MicroSim？」
- A) 小规模的嵌入式模拟 ✓
- B) 生物学中研究的微生物
- C) 对微处理器运行的模拟
- D) 微缩实体模型

所有选项都含「micro」和「sim」，但在本语境下只有 A 正确。

### 模式 2：部分定义

取正确定义的一部分，与错误元素拼接。

**示例：**
正确定义：「一种映射概念间先修关系的有向图」

干扰项：
- 「一种可视化学生进度的有向图」（结构对，目的错）
- 「一种映射先修关系的无向图」（目的对，结构错）
- 「一个显示学习顺序的有向列表」（结构错，目的相关）

### 模式 3：程度或范围

改变陈述的强度或范围。

**示例：**
题目：「一章的概念应有多少比例被测验覆盖？」
- A) 25–50%
- B) 50–75%
- C) 75–85% ✓
- D) 100%

全都可信，但 C 代表推荐的目标。

### 模式 4：时机或顺序

改变某件事发生的时间或先后顺序。

**示例：**
题目：「脚手架应该在什么时候开始撤除？」
- A) 在教学开始之前
- B) 在初始教学期间
- C) 随着能力的发展 ✓
- D) 在掌握很久之后

## 质量检查清单

对每个干扰项核实：

- [ ] **可信：** 没学过该材料的人会觉得它是对的吗？
- [ ] **有教学性：** 能测试理解或揭示误解吗？
- [ ] **语法通顺：** 能与题干在语法上衔接吗？
- [ ] **长度合适：** 与正确答案长度相近吗？
- [ ] **公平：** 不是陷阱或琐碎细节吗？
- [ ] **互不重叠：** 不与其他选项重叠吗？
- [ ] **风格一致：** 与其他选项使用相同的术语/语气吗？
- [ ] **无绝对化用词：** 避免「总是」「从不」「所有」「都不」（除非它本身是正确答案）吗？

## 常见错误

### 错误 1：无意义选项

❌ 「什么是学习图谱？」
- A) 紫色大象在跳舞
- B) 数字 42
- C) 显示概念依赖关系的有向图 ✓
- D) 我奶奶的食谱

**为什么错：** 不可信、没有教学价值、侮辱学生。

### 错误 2：某个干扰项特别长

❌ 「什么是 ISO 11179？」
- A) 一种汽车型号
- B) 一项元数据注册标准，为各机构在术语表和数据字典中创建精确、简洁、互不相同且不循环的定义提供指导 ✓
- C) 一个数字
- D) 一种图

**为什么错：** 长度泄露了正确答案。

### 错误 3：多个正确答案

❌ 「哪一项对学习很重要？」
- A) 先修知识 ✓
- B) 练习 ✓
- C) 示例 ✓
- D) 睡眠 ✓

**为什么错：** 全都可以被辩护为正确，题目有歧义。

### 错误 4：选项互相重叠

❌ 「多少百分比算好的概念覆盖率？」
- A) 50–70%
- B) 60–80% ✓
- C) 70–90%
- D) 80–100%

**为什么错：** 选项重叠；70% 既可以算 B 也可以算 C。

## 干扰项质量评分

用 0–1 的量表给每个干扰项打分：

**1.0（优秀）：**
- 高度可信
- 测试理解
- 能区分知识水平
- 公平且有教学价值

**0.8（良好）：**
- 可信
- 有教学价值
- 公平
- 有小瑕疵

**0.6（合格）：**
- 还算可信
- 有一定教学价值
- 公平但可以更好

**0.4（较差）：**
- 不太可信
- 教学价值有限
- 可能略有不公平

**0.2（很差）：**
- 不可信
- 无教学价值
- 可能不公平

**0.0（不可接受）：**
- 无意义
- 脑筋急转弯
- 明显不公平

**整题干扰项质量：**
取三个干扰项分数的平均值。

目标：平均干扰项质量 0.80 以上。

## 按布鲁姆层级给出的示例

### 记忆层级（Remember）

好的干扰项使用相关术语或相似概念。

题目：「DAG 是什么的缩写？」
- A) Data Analysis Graph（数据分析图）
- B) Directed Acyclic Graph（有向无环图）✓
- C) Digital Academic Guide（数字学术指南）
- D) Dynamic Assessment Grid（动态评估网格）

所有干扰项都使用相同的字母缩写，搭配听起来可信的术语。

### 理解层级（Understand）

好的干扰项测试理解的深度。

题目：「学习图谱为什么是有向的？」
- A) 为了看起来更专业
- B) 为了表明哪些概念依赖于其他概念 ✓
- C) 为了节省存储空间
- D) 为了更容易绘制

B 需要理解其目的；其他选项对没学过的人来说也可信。

### 应用层级（Apply）

好的干扰项给出看似合理但错误的应用。

题目：「为一门新课程创建学习图谱时，第一步应该做什么？」
- A) 画出可视化布局
- B) 选择图可视化软件
- C) 识别核心概念 ✓
- D) 确定配色方案

听起来都像合理的步骤，但 C 必须先做。

### 分析层级（Analyze）

好的干扰项要求区分相关的要素。

题目：「什么迹象表明学习图谱结构不良？」
- A) 超过 100 个概念
- B) 依赖结构中存在环 ✓
- C) 使用了技术术语
- D) 可视化布局复杂

需要分析什么让学习图谱有效、什么让它无效。

## 修订策略

如果某个干扰项太明显或不可信：

1. **增加具体性：** 让它更详细、更真实
2. **使用领域术语：** 纳入正确的专业词汇
3. **基于误解：** 研究常见的学生错误
4. **检查平行结构：** 确保语法一致
5. **调整长度：** 与其他选项对齐
6. **测试可信性：** 没学过的人会选它吗？

---

## 最后的建议

**黄金法则：**

> 每个干扰项都应当是一个尚未学会该材料的、理性的学生可能真心相信为正确的选项。

**教学法则：**

> 每个干扰项都应当帮助你了解学生知道什么、不知道什么。

**公平法则：**

> 每个干扰项都应当考查学科知识，而不是应试技巧。
