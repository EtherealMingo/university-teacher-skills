# 实证研究自动化 (Empirical Research Automation)

## 技能描述

运用 AI 自动化实证研究的完整工作流程，从资料收集、程式码转换、统计分析到论文撰写，大幅提升研究效率并确保研究可重现性。适用于教育科技、社会科学、心理学等需要量化分析的实证研究领域。

## 适用情境

- **复制经典研究**：将旧版统计软件（Stata, SPSS）代码转换为现代 Python/R，延伸分析到最新资料
- **资料收集自动化**：自动爬取政府开放资料、学术数据库、问卷平台等多元资料来源
- **统计分析加速**：快速生成描述性统计、推论统计与专业视觉化图表
- **文献回顾整理**：系统化搜寻、萃取、组织相关文献并生成回顾章节草稿
- **论文撰写辅助**：协助撰写研究方法、结果、讨论等章节，符合学术写作规范
- **可重现性套件**：建立完整的 GitHub 专案，包含资料、程式码、文档与执行说明
- **准实验资料分析**：处理教育介入研究的前后测资料，执行 ANCOVA 等统计方法

## 实证研究自动化工作流

```
阶段 1：资料准备
  ├─ 程式码现代化（Stata → Python/R）
  ├─ 网络资料爬取
  └─ 资料清理与整并
          ↓
阶段 2：统计分析
  ├─ 描述性统计
  ├─ 推论统计（t检定、ANOVA、回归）
  └─ 视觉化图表（符合 APA 格式）
          ↓
阶段 3：知识整合
  ├─ 文献回顾自动化
  ├─ 理论框架建构
  └─ 研究缺口识别
          ↓
阶段 4：论文产出
  ├─ 各章节草稿生成
  ├─ 学术语气调整
  └─ GitHub 可重现性套件
```

【研究设计】
[例如：非等组前后测设计（实验组 vs 控制组）]

【变项资讯】
- 自变项（独立变项）：[例如：教学方法（游戏化 vs 传统）]
- 依变项（结果变项）：[例如：学习成就后测、学习动机、批判思考]
- 共变项（控制变项）：[例如：学习成就前测、性别、年龄]

【样本资讯】
- 实验组样本数：[例如：30 人]
- 控制组样本数：[例如：28 人]
- 测量时间点：[例如：前测、立即后测、延宕后测（3 周后）]

【分析需求】
请选择适当的统计方法并执行以下分析：

1. **描述性统计**
   - 各组在前测、后测的平均数、标准差
   - 检查资料分布（直方图、Q-Q 图）

2. **推论统计**
   - 选择适当统计方法（建议 ANCOVA，以前测为共变项）
   - 检验统计假设（常态性、变异数同质性、回归斜率同质性）
   - 计算效果量（partial η² 或 Cohen's d）

3. **视觉化图表**
   - 组别比较长条图（含误差线）
   - 前后测变化折线图
   - 符合 APA 第七版格式

请提供：
1. Python 或 R 完整分析脚本
2. APA 格式统计表格（可直接放入论文）
3. 高分辨率图表档案（PNG 或 PDF）
4. 统计结果文字描述（适合论文结果章节）

## 最佳实践

### ✅ 研究伦理
- 确保资料收集符合 IRB（人体研究伦理委员会）规范
- 爬取资料时遵守网站使用条款，避免侵害著作权
- 保护个人隐私资料，进行去识别化处理
- 适当引用原始研究，避免学术剽窃

### ✅ 可重现性原则
- 使用版本控制（Git）追踪所有程式码与文件变更
- 记录完整的计算环境（Python 版本、套件版本）
- 提供原始资料或资料获取方法说明
- 撰写清晰的程式码注解与 README 文件

### ✅ 统计严谨性
- 报告完整的统计资讯（不仅是 p 值，包含信赖区间、效果量）
- 进行统计假设检定（常态性、变异数同质性等）
- 执行敏感性分析与稳健性检定
- 避免 p-hacking（反复分析寻找显著结果）

### ✅ AI 辅助写作伦理
- 将 AI 视为写作助手，所有内容需经人工审阅、修改、验证
- 在论文致谢中说明使用 AI 工具的方式
- 确保引用正确且完整，避免 AI 生成的虚假引用
- 维持论文逻辑连贯性与学术诚信
