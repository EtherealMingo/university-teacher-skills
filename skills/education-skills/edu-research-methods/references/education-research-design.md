# 教育研究设计 (Educational Research Design)

## 技能描述
协助教育研究者设计严谨的研究计划，包括研究问题形成、研究方法选择、资料收集与分析策略规划。

### 依方法分类

| 典范 | 方法论 | 资料类型 | 适用情境 |
|------|--------|---------|---------|
| 量化 | 实验、准实验、调查 | 数据、量表 | 验证假设、推论母群 |
| 质性 | 个案、现象学、扎根 | 访谈、观察、文件 | 理解经验、建构意义 |
| 混合 | 并行、解释性序列、探索性序列 | 兼具 | 深度与广度兼顾 |

## 提示词范本

### 研究问题发展
```
请协助我发展教育研究问题：

【研究领域】
大领域：[如：AI教育、数位学习、偏乡教育]
具体主题：[更具体的面向]

【问题意识来源】
- 实务观察：[教学现场发现的问题]
- 文献缺口：[现有研究的不足]
- 政策需求：[政策面的议题]

【初步想法】
我想探究的是：[初步描述]

【研究条件】
- 可接触的研究对象：[描述]
- 可用资源：[时间、经费、设备]
- 研究者背景：[专长、经验]

请协助：
1. 将想法聚焦为明确的研究问题
2. 建议 2-3 个可行的研究问题方向
3. 分析各方向的研究价值与可行性
4. 建议合适的研究方法取向
5. 提醒潜在的研究伦理议题
```

### 研究设计规划
```
请协助规划以下研究的设计：

【研究资讯】
研究问题：[明确陈述]
研究目的：[列出]

【研究取向】
偏好的研究典范：[量化/质性/混合/不确定]
研究类型：[实验/调查/个案/行动研究/其他]

【研究条件】
- 可接触对象：[描述]
- 研究期程：[时间]
- 研究资源：[列举]

【期望产出】
- 学位论文
- 期刊发表
- 政策建议
- 实务改进
- 其他：[说明]

请设计：
1. 建议的研究设计类型与理由
2. 研究对象选取策略
3. 变项定义与测量（量化）或研究焦点（质性）
4. 资料收集方法与工具
5. 资料分析策略
6. 研究效度/可信赖度确保策略
7. 预期研究时程表
8. 研究伦理考量
```

### 研究假设/待答问题撰写
```
请协助撰写研究假设或待答问题：

【研究背景】
研究主题：[主题]
研究目的：[目的]
理论依据：[简述支持的理论或文献]

【变项说明】（量化研究适用）

请提供：
【量化研究】
1. 虚无假设与对立假设（标准格式）
2. 操作型定义建议
3. 统计考验方法建议

【质性研究】
1. 核心研究问题
2. 次研究问题
3. 探究焦点说明
```

## 常见研究设计

### 准实验设计
```
不等组前后测设计：

          前测    实验处理    后测
实验组：  O1      X          O2
控制组：  O3      -          O4

适用情境：无法随机分派（如班级教学研究）
分析方法：共变数分析 (ANCOVA)
威胁控制：前测作为共变数控制组间初始差异
```

### 个案研究设计
```
嵌入式多重个案设计：

┌─────────────────────────────────────┐
│           研究脉络/场域              │
├─────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐          │
│  │ 个案一  │  │ 个案二  │  ...     │
│  ├─────────┤  ├─────────┤          │
│  │ 单位 A │  │ 单位 A │          │
│  │ 单位 B │  │ 单位 B │          │
│  └─────────┘  └─────────┘          │
└─────────────────────────────────────┘

适用情境：探究复杂现象、建构理论
分析方法：个案内分析 + 跨个案分析
```

### 设计本位研究 (DBR)
```
循环迭代设计：

     分析 → 设计 → 发展 → 实施 → 评估
       ↑                          │
       └──────────────────────────┘
              (迭代修正)

特色：
- 理论与实务双向发展
- 在真实情境中进行
- 与实务工作者协作
- 产出设计原则
```

### 行动研究设计
```
循环行动研究模式：

    ┌─→ 计划 (Plan)
    │       ↓
    │   行动 (Act)
    │       ↓
    │   观察 (Observe)
    │       ↓
    └── 反思 (Reflect)

适用情境：教师改进教学实务
特色：研究者即实践者、循环改进
```

## 偏乡教育研究注意事项

### 研究伦理
- 避免将偏乡学校“问题化”
- 尊重在地知识与文化
- 确保研究对社区有回馈
- 保护参与者隐私（小规模社区尤其重要）

### 方法调适
- 考量交通与时间成本
- 弹性调整资料收集方式
- 善用远距工具但注意数位落差
- 建立长期信任关系

### 文化敏感度
- 了解当地文化脉络
- 与在地教师/社区合作
- 研究发现要回馈社区
- 避免以都会标准评判
