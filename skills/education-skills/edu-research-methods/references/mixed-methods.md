# 混合研究方法 (Mixed Methods Research)

## 技能描述
整合量化与质性研究方法，发挥两种方法的优势，对复杂的教育现象进行更全面深入的探究。

## 混合研究的价值

### 为什么选择混合研究？
```
量化研究优势                 质性研究优势
• 可推论母群                 • 深度理解
• 因果关系检验               • 脉络掌握
• 客观数据                   • 参与者观点
• 可重复验证                 • 弹性探索
        ↘                    ↙
           混合研究
         • 互补 (Complementarity)
         • 验证 (Triangulation)
         • 拓展 (Expansion)
         • 解释 (Explanation)
```

### 适用情境
- 量化结果需要质性解释
- 质性发现需要量化验证
- 研究问题具有多重面向
- 需要发展并测试新工具
- 政策研究需要数据与故事

## 混合研究设计类型

### 1. 并行设计 (Convergent Design)
```
        ┌─────────────────┐
        │     研究问题     │
        └────────┬────────┘
                 │
        ┌────────┴────────┐
        ↓                 ↓
  ┌───────────┐     ┌───────────┐
  │ 量化资料   │     │ 质性资料   │
  │  收集      │     │  收集      │
  └─────┬─────┘     └─────┬─────┘
        │                 │
  ┌─────┴─────┐     ┌─────┴─────┐
  │ 量化分析   │     │ 质性分析   │
  └─────┬─────┘     └─────┬─────┘
        │                 │
        └────────┬────────┘
                 ↓
        ┌─────────────────┐
        │   整合比较       │
        │   结果诠释       │
        └─────────────────┘

时机：同时进行
目的：三角验证、互补
权重：通常 QUAN = QUAL
```

### 2. 解释性序列设计 (Explanatory Sequential)
```
        ┌─────────────────┐
        │     研究问题     │
        └────────┬────────┘
                 │
        ┌────────┴────────┐
        ↓                 │
  ┌───────────┐           │
  │ 第一阶段   │           │
  │ 量化资料   │ ────────→ │ 量化结果
  │ 收集分析   │           │ 需要解释
  └─────┬─────┘           │
        │                 │
        │ ←────────────────┘
        ↓
  ┌───────────┐
  │ 第二阶段   │
  │ 质性资料   │ → 解释量化结果
  │ 收集分析   │
  └─────┬─────┘
        ↓
  ┌───────────┐
  │  整合诠释  │
  └───────────┘

时机：量化先、质性后
目的：解释量化结果
权重：通常 QUAN > qual
```

### 3. 探索性序列设计 (Exploratory Sequential)
```
        ┌─────────────────┐
        │     研究问题     │
        └────────┬────────┘
                 │
        ┌────────┴────────┐
        ↓                 │
  ┌───────────┐           │
  │ 第一阶段   │           │
  │ 质性资料   │ ────────→ │ 发展工具/
  │ 收集分析   │           │ 提出假设
  └─────┬─────┘           │
        │                 │
        │ ←────────────────┘
        ↓
  ┌───────────┐
  │ 第二阶段   │
  │ 量化资料   │ → 验证/推论
  │ 收集分析   │
  └─────┬─────┘
        ↓
  ┌───────────┐
  │  整合诠释  │
  └───────────┘

时机：质性先、量化后
目的：探索建构→量化验证
权重：通常 qual → QUAN
```

## 整合策略

### Joint Display（联合展示）
```
┌──────────────────────────────────────────────────┐
│            研究发现联合展示表                      │
├────────────┬────────────┬────────────────────────┤
│ 研究面向   │ 量化发现    │ 质性发现              │
├────────────┼────────────┼────────────────────────┤
│ 面向 A     │ 统计结果   │ 主题/引述             │
├────────────┼────────────┼────────────────────────┤
│ 面向 B     │ 统计结果   │ 主题/引述             │
├────────────┼────────────┼────────────────────────┤
│ 整合诠释   │ 两种结果如何互相支持/解释/挑战      │
└────────────┴────────────┴────────────────────────┘
```

### 结果对话类型
| 类型 | 说明 | 诠释方向 |
|------|------|----------|
| 收敛 | 量化与质性结论一致 | 增强信心、三角验证 |
| 互补 | 各自揭示不同面向 | 丰富理解、多元视角 |
| 歧异 | 结果不一致或矛盾 | 深入探究、修正理解 |
| 拓展 | 一方结果拓展另一方 | 新发现、后续研究 |

## 品质指标

### 混合研究品质检核
```
量化品质
□ 效度（内容、建构、效标）
□ 信度（内部一致性、再测）
□ 统计结论效度
□ 外在效度（可推论性）

质性品质
□ 可信度 (Credibility)
□ 可转换性 (Transferability)
□ 可靠性 (Dependability)
□ 可确认性 (Confirmability)

混合研究特有品质
□ 设计品质（适切性、严谨性）
□ 整合品质（整合程度、诠释品质）
□ 整体推论品质
```

## AI/数位学习研究的混合设计范例

### 研究主题：AI 辅助差异化教学成效
```
探索性序列设计：

第一阶段（质性）
- 访谈教师理解差异化教学困难
- 观察课堂了解实施现况
- 发展 AI 辅助方案原型

第二阶段（量化）
- 准实验设计检验成效
- 前后测比较学习表现
- 问卷调查态度与满意度

整合
- 将质性发现转化为量化变项
- 用量化验证质性观察
- 整合说明 AI 辅助的作用机制
```
