# 生成式 AI 教育应用 (Generative AI in Education)

## 技能描述
深入探讨生成式 AI（如 GPT、Gemini）在教育领域的各种应用模式，从备课、教学、评量到学生自学。

## 教师端应用

### 1. 备课助手

#### 提示词范本：课程大纲生成
```
请担任资深[科目]教师，帮我设计一学期的课程大纲：

【课程资讯】
科目：[科目名称]
年级：[年级]
每周节数：[节数]
学期周数：[周数]

【课纲依据】
核心素养：[素养代码]
学习表现：[表现代码]
学习内容：[内容代码]

【学生背景】
程度描述：[描述]
先备知识：[列举]

请设计包含：
1. 各周教学主题与目标
2. 重要概念的逻辑顺序
3. 评量时间点安排
4. 跨领域连结机会
5. 差异化教学切入点
```

#### 提示词范本：单元教材编写
```
请帮我编写以下单元的教材内容：

【单元资讯】
科目：[科目]
单元名称：[名称]
教学节数：[节数]
学习目标：
1. [目标1]
2. [目标2]
3. [目标3]

【教材需求】
- 引起动机素材
- 核心概念说明（适合[年级]学生阅读）
- 生活化范例 3-5 个
- 常见迷思概念与澄清
- 重点整理

【风格要求】
- 语言程度：适合[年级]
- 语气：[亲切/正式/活泼]
- 特殊需求：[如：融入在地元素]
```

### 2. 评量设计

#### 提示词范本：多元题型生成
```
请为以下主题设计多元评量题目：

【主题资讯】
科目：[科目]
主题：[主题名称]
认知层次分布：
- 记忆理解：[%]
- 应用分析：[%]
- 评鉴创造：[%]

【题型需求】
1. 选择题：[题数]
2. 是非题：[题数]
3. 配合题：[题数]
4. 填空题：[题数]
5. 简答题：[题数]
6. 申论题：[题数]

【难度分布】
- 基础：[%]
- 中等：[%]
- 挑战：[%]

请提供：
- 完整题目
- 正确答案
- 评分标准（申论题）
- 试题分析（双向细目表）
```

### 3. 个别化回馈

#### 提示词范本：作业回馈生成
```
请针对以下学生作业提供个别化回馈：

【作业资讯】
科目：[科目]
作业主题：[主题]
评量规准：
1. [规准1]：[满分]
2. [规准2]：[满分]
3. [规准3]：[满分]

【学生作答内容】
[贴上学生作业内容]

【学生背景】
学习程度：[高/中/低]
性格特质：[描述]
过去表现：[描述]

请提供：
1. 各规准评分与说明
2. 具体优点（至少2点）
3. 待改进处与建议（具体可行）
4. 鼓励性结语
5. 延伸学习建议

回馈语气：[鼓励/中性/严谨]
```

## 学生端应用

### 1. AI 学习导师

#### 提示词范本：概念学习
```
我是[年级]学生，正在学习[科目]的[主题]。

我的疑问是：
[学生的具体问题]

我目前的理解是：
[学生描述自己的想法]

请帮助我：
1. 不要直接给答案，用苏格拉底式提问引导我思考
2. 如果我的理解有误，温和地指出并解释
3. 用我能理解的例子说明
4. 给我一个练习题检验我的理解
```

### 2. 写作伙伴

#### 提示词范本：写作辅助
```
我要写一篇[文体]：

【题目】[题目或主题]

【写作目的】[说明目的]

【目前进度】
[贴上目前的草稿]

请帮我：
- [ ] 检查文章结构是否完整
- [ ] 指出论点不清楚的地方
- [ ] 建议可以增加的论据
- [ ] 检查语句是否通顺
- [ ] 提供改善建议（不要直接改写）

注意：请用提问方式引导我自己修改，而不是直接给我修改后的版本。
```

### 3. 练习伙伴

#### 提示词范本：互动练习
```
请当我的[科目]练习伙伴：

【练习主题】[主题]
【我的程度】[描述]
【练习目标】[目标]

规则：
1. 一次只给一题
2. 等我回答后再给反馈
3. 如果我答错，给提示而非答案
4. 答对后提供变化题巩固
5. 记录我的正确率

开始吧！
```

## 最佳实践

### 提示词工程技巧

```
有效提示词的要素：
┌─────────────────────────────────────┐
│  1. 角色设定 (Role)                  │
│     “请担任资深国中数学教师...”     │
├─────────────────────────────────────┤
│  2. 任务说明 (Task)                  │
│     “帮我设计一份学习单...”        │
├─────────────────────────────────────┤
│  3. 情境脉络 (Context)               │
│     “学生程度较弱，需要鹰架...”    │
├─────────────────────────────────────┤
│  4. 格式要求 (Format)                │
│     “请以表格呈现，包含...”        │
├─────────────────────────────────────┤
│  5. 范例提供 (Example)               │
│     “类似这种风格：...”            │
├─────────────────────────────────────┤
│  6. 限制条件 (Constraints)           │
│     “避免使用超过500字...”         │
└─────────────────────────────────────┘
```

### 品质检核

```
AI 生成内容检核清单：
□ 事实正确性：是否有错误资讯？
□ 适龄性：语言和内容适合学生年龄？
□ 文化敏感度：是否有偏见或不当内容？
□ 教学适切性：符合教学目标？
□ 原创性：不过度依赖 AI 原文？
□ 版权：是否涉及版权问题？
```

## 各 AI 模型比较

### 教育应用特性比较

| 特性 | GPT-4 | Gemini |
|------|-------|--------|
| 长文处理 | ★★★★ | ★★★★ |
| 逻辑推理 | ★★★★★ | ★★★★ |
| 创意发想 | ★★★★★ | ★★★★ |
| 中文能力 | ★★★★ | ★★★ |
| 即时搜寻 | ★★★★ | ★★★★★ |
| 多模态 | ★★★★★ | ★★★★★ |
| 安全性 | ★★★★ | ★★★★ |
| 教育特化 | ★★★★ | ★★★ |

### 场景选择建议

| 教育场景 | 首选 | 备选 | 原因 |
|---------|------|------|------|
| 教案撰写 | GPT-4 | Gemini | 长文逻辑佳 |
| 创意活动设计 | GPT-4 | Gemini | 创意多元 |
| 时事素材搜集 | Gemini | GPT-4 | 即时搜寻 |
| 数学推导 | GPT-4 | Gemini | 步骤严谨 |
| 语言学习 | GPT-4 | Gemini | 语言多元 |
| 图像教材 | GPT-4 (DALL-E) | Gemini | 整合方便 |
