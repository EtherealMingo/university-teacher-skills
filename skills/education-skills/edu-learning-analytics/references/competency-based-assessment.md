# 素养导向评量 (Competency-Based Assessment)

## 技能描述
设计符合108课纲精神的素养导向评量，强调真实情境、跨领域整合、高层次思考，评估学生在真实情境中运用知识与技能解决问题的能力。

## 适用情境
- 段考/期末考命题设计
- 形成性评量规划
- 素养导向学习单设计
- 跨领域统整评量
- 多元评量工具开发

## 评量设计架构

### 双向细目表对应
| 认知层次 | 记忆理解 | 应用分析 | 评鉴创造 |
|----------|----------|----------|----------|
| 核心概念 | 基础题 | 情境题 | 探究题 |
| 学习表现 | 识别定义 | 推理解释 | 设计评估 |
| 建议比例 | 30% | 50% | 20% |

### 素养题型分类
| 题型 | 特征 | 适用情境 |
|------|------|----------|
| 情境选择题 | 结合生活情境的选择题 | 大规模测验 |
| 非连续文本题 | 图表、数据判读 | 阅读素养评量 |
| 探究实作题 | 设计实验、提出假设 | 科学探究 |
| 议题讨论题 | 多元观点分析 | 社会议题 |
| 跨领域整合题 | 结合多学科知识 | 统整学习 |

## 评分规准设计

### Rubric 设计原则
```
四等第评分规准范例

┌──────────┬─────────────────────────────────────┐
│ 等第     │ 表现描述                             │
├──────────┼─────────────────────────────────────┤
│ 优（A）  │ 完整掌握概念，能灵活运用于新情境，   │
│          │ 展现批判思考与创意                   │
├──────────┼─────────────────────────────────────┤
│ 良（B）  │ 大致掌握概念，能正确应用于标准情境， │
│          │ 推理过程大致正确                     │
├──────────┼─────────────────────────────────────┤
│ 可（C）  │ 部分掌握概念，应用时有错误，         │
│          │ 需要提示才能完成                     │
├──────────┼─────────────────────────────────────┤
│ 待加强（D）│ 概念理解有明显错误或缺漏，          │
│          │ 无法独立完成基本任务                 │
└──────────┴─────────────────────────────────────┘
```

## 常见迷思与改进

### 命题常见问题
| 问题 | 改进建议 |
|------|----------|
| 情境牵强 | 使用学生真正可能遇到的生活情境 |
| 阅读量过大 | 精简题干，聚焦核心问题 |
| 认知层次偏低 | 增加需要推理、判断的题目 |
| 答案唯一 | 设计允许多元解答的开放题 |
| 评分主观 | 建立明确的评分规准 |

## 偏乡应用考量

### 情境在地化
- 使用偏乡学生熟悉的生活情境
- 融入原住民族文化元素
- 考量学生先备经验差异

### 实施弹性
- 提供口头作答选项
- 允许使用母语辅助表达
- 适度调整时间限制
