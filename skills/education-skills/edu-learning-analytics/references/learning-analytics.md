# 学习分析技术 (Learning Analytics)

## 技能描述
运用数据分析技术收集、分析与诠释学生学习历程数据，以优化教学决策、预测学习成效、提供个人化学习支援。

## 适用情境
- 线上学习平台数据分析
- 学生学习预警系统建置
- 教学成效评估
- 学习路径优化
- 班级/学校层级的学习成效追踪

## 学习分析层次

```
┌─────────────────────────────────────────────┐
│           描述性分析 (Descriptive)           │
│     “发生了什么？”                         │
│     • 学习时间统计                           │
│     • 完成率追踪                             │
│     • 成绩分布                               │
├─────────────────────────────────────────────┤
│           诊断性分析 (Diagnostic)            │
│     “为什么发生？”                         │
│     • 错误模式分析                           │
│     • 学习行为关联                           │
│     • 影响因素探究                           │
├─────────────────────────────────────────────┤
│           预测性分析 (Predictive)            │
│     “可能会发生什么？”                     │
│     • 学习成效预测                           │
│     • 退选/辍学风险                          │
│     • 学习困难预警                           │
├─────────────────────────────────────────────┤
│           处方性分析 (Prescriptive)          │
│     “应该怎么做？”                         │
│     • 学习路径建议                           │
│     • 介入策略推荐                           │
│     • 资源配置优化                           │
└─────────────────────────────────────────────┘
```

## 关键指标 (KPIs)

### 学习参与指标
| 指标 | 计算方式 | 参考值 |
|------|----------|--------|
| 登入频率 | 每周登入次数 | 3-5次/周 |
| 学习时长 | 累计在线时间 | 依课程设计 |
| 完成率 | 已完成/总单元数 | >80% |
| 互动频率 | 讨论/提问次数 | 依班级规模 |

### 学习成效指标
| 指标 | 计算方式 | 警戒值 |
|------|----------|--------|
| 形成性评量平均 | 各次测验平均 | <60分 |
| 进步幅度 | (后测-前测)/前测 | 负成长 |
| 概念掌握率 | 正确概念数/总概念数 | <70% |
| 作业缴交率 | 已缴交/应缴交 | <80% |

### 预警指标
| 风险等级 | 特征 | 建议行动 |
|----------|------|----------|
| 高风险 | 连续3天未登入、成绩低于30分 | 立即联系、个别辅导 |
| 中风险 | 完成率<50%、成绩40-60分 | 关怀提醒、同侪支援 |
| 低风险 | 完成率<70%、成绩60-70分 | 一般追踪、鼓励 |

## 提示词范本

### 学习数据分析报告
```
请分析以下班级学习数据，生成分析报告：

【班级资讯】
班级：[班级名称]
人数：[人数]
课程：[课程名称]
分析期间：[起讫日期]

【数据摘要】
- 平均登入次数：[次数]
- 平均学习时长：[时数]
- 平均测验成绩：[分数]
- 作业缴交率：[百分比]
- 成绩分布：[各分数段人数]

【问题描述】
[教师观察到的现象或疑问]

请提供：
1. 数据趋势分析
2. 学习困难学生辨识
3. 可能的原因诊断
4. 具体的教学调整建议
5. 下一步数据收集建议
```

### 个别学生学习诊断
```
请诊断这位学生的学习状况：

【学生资料】
学生代码：[代码]
年级：[年级]

【学习行为数据】
- 登入时间分布：[描述]
- 平均每次学习时长：[分钟]
- 影片观看完成率：[百分比]
- 暂停/重播频率：[频率]

【学习成效数据】
- 各单元测验成绩：[列表]
- 错误题型分布：[类型与次数]
- 作业完成品质：[评语]

【比较基准】
- 班级平均：[相关数据]

请分析：
1. 学生的学习模式特征
2. 优势与待加强领域
3. 可能的学习障碍
4. 个人化学习建议
5. 教师/家长可采取的支援行动
```

```
请协助设计一个学习预警系统：

【场域描述】
学校类型：[国小/国中/高中/大学]

【可用数据】
```

## 偏乡应用考量

### 数据收集挑战
- 设备/网络限制导致数据不完整
- 学生共用设备造成识别困难
- 教师数位能力差异

### 因应策略
- 设计离线数据收集机制
- 简化仪表板设计
- 提供教师培训与支援
- 结合质性观察纪录

## 伦理与隐私

### 资料处理原则
- 最小必要原则：仅收集必要数据
- 匿名化处理：移除可识别资讯
- 知情同意：告知学生/家长
- 安全储存：加密与存取控制

### 使用伦理
- 避免标签化学生
- 数据辅助而非取代专业判断
- 注意算法偏见
- 确保公平使用
