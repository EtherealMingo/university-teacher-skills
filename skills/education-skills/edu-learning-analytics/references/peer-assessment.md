# 同侪互评机制设计 (Peer Assessment Mechanism Designer)

## 技能描述

设计有效的同侪评量与回馈机制，培养学生批判思考、自我评量与建设性回馈能力。透过结构化的评分规准（Rubric）、评量者训练与品质保证机制，提升互评的信效度与学习价值，同时减轻教师评量负担。

## 适用情境

- **写作互评**：作文、报告、论文初稿的同侪评阅与回馈
- **概念图互评**：图形组织作品的结构与内容品质评鉴
- **口头报告评估**：简报技巧、内容组织、表达清晰度的同侪评分
- **专案作品评量**：设计作品、程式作业、艺术创作的多维度评估
- **小组贡献评量**：团队协作中个人贡献度的 360 度评鉴
- **线上讨论品质**：论坛发言、讨论参与的深度与品质评估
- **游戏化互评**：结合积分、徽章系统的趣味化同侪评量
- **偏乡应用**：纸本互评表单、实体回馈卡片的低技术实施方案

## 同侪互评流程架构

```
阶段 1：准备阶段
  ├─ 设计评分规准（Rubric）
  ├─ 准备标竿范例（不同等级作品）
  └─ 训练评量者（口径校正）
          ↓
阶段 2：作品提交
  ├─ 设定提交规范（格式、期限）
  ├─ 去识别化处理（若采匿名）
  └─ 分配评量者（随机/分层）
          ↓
阶段 3：执行互评
  ├─ 使用 Rubric 评分
  ├─ 撰写文字回馈
  └─ 教师监控品质
          ↓
阶段 4：回馈整合
  ├─ 汇整多位评量者意见
  ├─ 学生阅读回馈
  └─ 反思与修改作品
          ↓
阶段 5：成绩计算
  ├─ 作品成绩（同侪分+教师分）
  ├─ 评量者成绩（评量品质）
  └─ 学习反思成绩
```

## 提示词范本

### 📋 Rubric 评分规准设计

请为以下学习作品设计详细的评分规准（Rubric）：

【作品类型】
[例如：国小五年级自然科“能源议题”概念图]

【学习目标】
[例如：
1. 正确识别至少 5 种能源类型
2. 建立能源之间的阶层关系
3. 标示能源优缺点与环境影响
4. 提出创新的交叉连结]

【评量目的】
- [X] 总结性评量（影响成绩）
- [X] 形成性评量（提供回馈）
- [ ] 自我评量（反思学习）

【评量者】
- [X] 同侪互评
- [X] 教师评分
- [ ] 自我评量

请设计 Rubric，包含：

1. **评量向度设定**（4-6 个向度）

   请识别关键评量向度，例如：
   - 向度 1：概念完整性（是否涵盖关键概念）
   - 向度 2：阶层结构（上位-下位概念组织）
   - 向度 3：连结正确性（关系标示适当）
   - 向度 4：交叉连结（创造性整合）
   - 向度 5：视觉呈现（清晰易读）

2. **等级量表设计**

   选择适当等级数：
   - [ ] 3 等级（超越/符合/接近标准）
   - [X] 4 等级（优秀/良好/尚可/待改进）
   - [ ] 5 等级（卓越/优秀/良好/尚可/待改进）

3. **详细 Rubric 内容**

   请为每个向度提供 4 个等级的描述：

   **向度 1：概念完整性**（权重 30%）

   | 等级 | 分数 | 描述（可观察、可测量） |
   |------|------|----------------------|
   | 优秀 | 4 | 包含 8 个以上关键概念，涵盖所有能源类型（太阳能、风能、水力、化石燃料等），并加入环境影响概念 |
   | 良好 | 3 | 包含 5-7 个关键概念，涵盖多数能源类型，概念正确 |
   | 尚可 | 2 | 包含 3-4 个概念，部分能源类型遗漏，或有少数概念错误 |
   | 待改进 | 1 | 包含少于 3 个概念，或概念错误较多 |

   （为每个向度提供完整表格）

4. **学生友善版 Rubric**

   将专业用语转换为学生易懂的语言：
   - “阶层结构”→“你的概念图有没有分类？大概念包含小概念？”
   - “交叉连结”→“你有没有找到不同分类之间的关系？”

5. **标竿范例说明**

   为每个等级提供作品范例或描述：
   - 优秀范例：“看看这个概念图，它有...”
   - 良好范例：“这个概念图做得不错，如果能...会更好”

请提供：
1. 完整 Rubric 表格（含所有向度与等级）
2. 学生友善版 Rubric
3. 标竿范例说明（或范例作品描述）
4. 教师使用指引（如何使用此 Rubric 评分）

### 🎓 评量者训练活动设计

设计训练学生成为有效评量者的工作坊：

【训练目标】
学生能够：
1. 理解并正确应用评分规准
2. 撰写具体、建设性、有帮助的回馈
3. 保持公平客观的评量态度

【目标学习者】
[例如：国中八年级，30 人，即将进行作文互评]

【训练时间】
[例如：1 节课 45 分钟]

请设计训练活动，包含：

1. **活动 1：回馈品质辨识**（15 分钟）

   教师提供：
   - 1 件范例作品（如：一篇作文段落）
   - 5-6 则不同品质的回馈范例

   回馈范例类型：
   - **优秀回馈**：“第二段的比喻很生动（‘时间像流水’），但第三段的论点可以加入具体例子支持，例如...”
   - **模糊回馈**：“写得很好”“需要改进”（无具体指引）
   - **过于批评**：“这段写得很差，完全看不懂”（负面语气）
   - **过于宽松**：“全部都很棒！没问题！”（无实质建议）

   学生任务：
   1. 阅读所有回馈
   2. 小组讨论：哪些回馈最有帮助？为什么？
   3. 归纳“高品质回馈”的特征

   教师总结：提出“高品质回馈检核清单”
   - [ ] 具体指出位置（“在第二段...”）
   - [ ] 说明优点或问题
   - [ ] 连结评分规准
   - [ ] 提供改进建议
   - [ ] 语气鼓励与尊重

2. **活动 2：Rubric 应用练习**（15 分钟）

   教师提供：
   - 2-3 件不同品质的范例作品
   - 评分规准 (Rubric)

   学生任务：
   1. 个人评分：使用 Rubric 为范例作品评分
   2. 小组讨论：比较评分结果，讨论差异
   3. 口径校正：全班讨论，教师说明标准答案与理由

   口径校正重点：
   - “优秀”与“良好”的界线在哪？
   - 如何判断“概念完整性”？
   - 常见评分错误有哪些？

3. **活动 3：回馈写作练习**（15 分钟）

   提供回馈框架（TAG 法或肯定-建议-鼓励法）：

   **TAG 回馈模板**：
   ```
   【T - Tell 我喜欢的部分】
   你的作品中，我觉得 ___ 很棒，因为 ___

   【A - Ask 我的疑问】
   我想问：___？ 或者我好奇 ___？

   【G - Give 我的建议】
   如果能 ___，你的作品会更好，例如 ___
   ```

   学生任务：
   1. 选择一件范例作品
   2. 使用 TAG 模板撰写回馈
   3. 两人配对互相检视回馈品质
   4. 全班分享优秀回馈范例

4. **总结与承诺**（5 分钟）

   - 回顾高品质回馈的要素
   - 学生签署“评量者承诺书”：
     - 我承诺公平评量
     - 我承诺给予建设性回馈
     - 我承诺尊重他人作品

请提供：
1. 完整训练活动教案（含时间分配）
2. 回馈范例集（好与不好的对比）
3. 学生活动单（含 TAG 回馈模板）
4. 评量者承诺书范本

### 🔄 同侪互评流程管理

设计完整的同侪互评实施流程与管理机制：

【课程资讯】
- 科目：[例如：国文科]
- 作业类型：[例如：议论文写作（800 字）]
- 班级人数：[例如：32 人]
- 互评时程：[例如：2 周（提交→互评→修改）]

【互评设定】
- 匿名评量：[X] 是  [ ] 否
- 每件作品评量者数：[例如：3 人]
- 每人评量件数：[例如：3 件]
- 成绩占比：作品 70%（同侪评分 40% + 教师评分 30%），评量品质 30%

请设计互评流程，包含：

1. **阶段 1：作品提交**（第 1-3 天）

   提交规范：
   - 格式：Word 档案，12pt 新细明体，行距 1.5 倍
   - 档名：学号_姓名_议论文.docx
   - 截止时间：第 3 天晚上 11:59
   - 提交平台：[例如：Google Classroom / 学校学习平台 / 纸本]

   去识别化处理（若匿名）：
   - 教师移除档案中的姓名资讯
   - 重新编号：A01, A02, A03... （使用代码）

2. **阶段 2：评量者分配**（第 4 天）

   分配策略：
   - [X] 随机分配（避免朋友互评偏误）
   - [ ] 能力分层（高/中/低能力互评）
   - [ ] 互惠评量（A 评 B，B 评 A）

   分配结果通知：
   - 每位学生收到 3 件作品代码（如：A05, A12, A23）
   - 下载作品档案或领取纸本
   - 收到评分规准与回馈模板

3. **阶段 3：执行互评**（第 5-10 天）

   评量任务：
   - 使用 Rubric 为每个向度评分
   - 撰写文字回馈（每件作品至少 100 字）
   - 提供具体改进建议

   教师监控：
   - 每天检视提交进度
   - 抽检评量品质（10-20% 作品）
   - 发现问题及时介入（如：敷衍评分、不当回馈）

   学生支援：
   - 设立答疑时段
   - 线上讨论区（厘清评分标准）

4. **阶段 4：回馈汇整与阅读**（第 11-12 天）

   教师处理：
   - 汇整每件作品的 3 份评量
   - 计算平均分数
   - 标记极端评分（与平均差距过大）
   - 进行教师复核（抽检或全数）

   学生收到：
   - 自己作品的 3 份同侪回馈
   - 平均分数与各向度得分
   - 教师补充意见（若有）

   反思任务：
   - 阅读所有回馈
   - 填写反思单：“哪些回馈最有帮助？为什么？”
   - 规划修改方向

5. **阶段 5：修改与再提交**（第 13-14 天）

   修改任务：
   - 根据回馈修改作品
   - 撰写“修改说明”（我根据回馈做了哪些修改？）
   - 提交最终版本

   成绩计算：
   - 初稿成绩（同侪评分平均）× 40%
   - 最终版成绩（教师评分）× 30%
   - 评量品质成绩 × 20%
   - 反思与修改 × 10%
   = 总成绩

6. **品质保证机制**

   评量品质检核：
   - 评分过于宽松或严格（与平均差距 > 1 分）→ 教师面谈
   - 文字回馈过短（< 50 字）→ 提醒补充
   - 不当回馈内容（攻击性、离题）→ 移除并重新分配
   - 优质回馈（被作者评为最有帮助）→ 加分奖励

   学生申诉机制：
   - 认为评分不公→ 提出申诉→ 教师复核→ 调整分数
   - 收到不当回馈→ 通报教师→ 移除回馈→ 教师介入处理

请提供：
1. 完整流程时程表（甘特图或时间轴）
2. 教师检核清单（每阶段要做什么）
3. 学生任务清单（每阶段缴交什么）
4. 评分计算 Excel 范本

### ⚖️ 互评伦理与公平性设计

设计同侪互评的伦理规范与争议处理机制：

【伦理关注点】
- 隐私保密（学生作品是否公开？）
- 评分公平（避免友谊/敌意偏误）
- 心理安全（学生能否承受批评？）
- 学术诚信（避免串通作弊）

请设计伦理规范与处理机制：

1. **隐私保密规范**

   规则设计：
   - 互评作品仅评量者与教师可见（不公开全班）
   - 匿名评量优先（双盲：作者与评量者均匿名）
   - 禁止截图或分享他人作品
   - 违反规定的处理方式

2. **公平性保证策略**

   潜在偏误与对策：

   | 偏误类型 | 现象 | 对策 |
   |---------|------|------|
   | 友谊偏误 | 给朋友高分 | 匿名评量、多评量者平均 |
   | 敌意偏误 | 故意给低分 | 教师监控、极端值处理 |
   | 宽严偏误 | 整体过松或过严 | 标准化训练、口径校正 |
   | 光环效应 | 所有向度给相同分数 | 提醒分向度独立评分 |
   | 能力差异 | 低成就学生评量品质较低 | 加强训练、教师复核 |

3. **心理安全支持**

   建立支持性文化：
   - 强调“回馈是帮助而非批评”
   - 教师示范接受回馈的态度
   - 使用“肯定-建议-鼓励”结构
   - 提供情绪支持管道（辅导老师）

   弱势学生保护：
   - 特殊需求学生的调整（如：可选择退出排行榜）
   - 低成就学生的鼓励（强调进步而非绝对分数）
   - 避免公开完整排名（只表扬前段，不揭露后段）

4. **学术诚信规范**

   禁止行为：
   - 串通作弊（互给高分）
   - 敷衍评量（随意给分、复制贴上回馈）
   - 恶意评量（故意给低分、人身攻击）

   侦测机制：
   - 统计分析：侦测异常互评模式（总是互相给高分）
   - 教师抽检：检视回馈品质
   - 同侪检举：提供匿名通报管道

   处理方式：
   - 初犯：警告、重新评量
   - 再犯：该次评量成绩不计分
   - 严重违规：依校规处理

5. **争议处理流程**

   **情境 1：学生认为评分不公**
   - Step 1：学生提出申诉（3 天内，需说明理由）
   - Step 2：教师检视作品与回馈
   - Step 3：对照 Rubric 判断
   - Step 4：决定维持或调整分数
   - Step 5：向学生说明理由

   **情境 2：收到不当回馈**
   - Step 1：学生通报教师
   - Step 2：教师审查回馈内容
   - Step 3：移除不当回馈
   - Step 4：与评量者面谈教育
   - Step 5：重新分配评量者（若需要）

6. **学生须知文件**

   设计“同侪互评学生手册”，包含：
   - 互评的目的与价值（为什么要做互评？）
   - 评量流程说明（时程表）
   - 权利与责任（我可以做什么？不可以做什么？）
   - 伦理规范（隐私、公平、尊重）
   - 申诉管道（遇到问题找谁？）
   - FAQ 常见问题

请提供：
1. 伦理规范文件（可张贴在教室或平台）
2. 争议处理流程图
3. 学生互评须知手册（Word 文件格式）
4. 家长说明信（若学生为国小/国中）

## 互评品质指标

| 指标 | 良好互评 | 不佳互评 |
|------|---------|---------|
| **评分一致性** | 与其他评量者差距 < 0.5 分 | 差距 > 1 分 |
| **回馈长度** | 100-200 字，充分说明 | < 50 字，过于简短 |
| **回馈具体性** | 指出具体位置与内容 | 模糊笼统（“很好”“改进”） |
| **建设性** | 提供改进建议与方法 | 只批评，无建议 |
| **连结标准** | 参照 Rubric 说明 | 未连结评分规准 |
| **语气** | 尊重、鼓励、支持 | 负面、批判、攻击 |

## 最佳实践

### ✅ 实施建议
- 从低风险开始（形成性评量→总结性评量）
- 充分训练后才正式实施（至少 1 节课训练）
- 多评量者以提升信度（建议 2-3 位）
- 同侪评分不宜占总成绩过高（20-40%）

### ✅ 偏乡友善实施
- 纸本互评表单（无须线上平台）
- 实体回馈卡片（手写回馈）
- 简化流程（减少复杂步骤）
- 善用小班优势（教师可更密切监控）

### ✅ 品质保证
- 定期检视评量品质（每次都抽检）
- 收集学生回馈改进流程（每学期检讨）
- 分析信效度资料（进阶应用）
