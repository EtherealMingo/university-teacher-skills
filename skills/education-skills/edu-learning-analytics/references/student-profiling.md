# 学生学习轮廓分析 (Student Learning Profiling)

## 技能描述
建立全面的学生学习轮廓，整合认知能力、学习风格、动机态度、社会背景等多维度资讯，支援个人化教学与辅导。

## 适用情境
- 新生入学评估
- 转学生适应辅导
- 特殊需求学生鉴定
- 生涯辅导规划
- 差异化教学分组依据

## 学习轮廓维度

### 多维度轮廓架构
```
                    ┌─────────────┐
                    │  学习轮廓   │
                    └──────┬──────┘
         ┌─────────────────┼─────────────────┐
         ↓                 ↓                 ↓
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│  认知维度   │   │  情意维度   │   │  社会维度   │
├─────────────┤   ├─────────────┤   ├─────────────┤
│ • 先备知识  │   │ • 学习动机  │   │ • 家庭背景  │
│ • 认知能力  │   │ • 自我效能  │   │ • 同侪关系  │
│ • 学习风格  │   │ • 学习态度  │   │ • 文化脉络  │
│ • 后设认知  │   │ • 兴趣偏好  │   │ • 资源可近性│
└─────────────┘   └─────────────┘   └─────────────┘
```

### 认知维度详解

| 面向 | 评估工具 | 资料来源 |
|------|---------|---------|
| 先备知识 | 诊断性前测 | 测验系统 |
| 认知能力 | 标准化测验 | 心理测验 |
| 学习风格 | VARK量表 | 问卷调查 |
| 后设认知 | 学习策略量表 | 自我报告 |

### 情意维度详解

| 面向 | 评估工具 | 资料来源 |
|------|---------|---------|
| 内在动机 | 学习动机量表 | 问卷调查 |
| 自我效能 | 自我效能量表 | 问卷调查 |
| 学习焦虑 | 焦虑量表 | 问卷/观察 |
| 兴趣 | 兴趣量表 | 问卷/访谈 |

### 社会维度详解

| 面向 | 资料来源 | 注意事项 |
|------|---------|---------|
| 家庭社经地位 | 家长问卷 | 保密处理 |
| 家庭支持度 | 亲师访谈 | 敏感议题 |
| 文化背景 | 学籍资料 | 尊重差异 |
| 资源可近性 | 环境调查 | 偏乡考量 |

## 提示词范本

### 建立学生学习轮廓
```
请协助我建立这位学生的学习轮廓：

【基本资料】
年级：[年级]
性别：[性别]
就读学校类型：[都会/偏乡/原乡]

【认知资料】
- 前测成绩：[各科成绩]
- 学习风格测验结果：[视觉/听觉/读写/动觉]
- 教师观察的学习特征：[描述]

【情意资料】
- 学习动机量表分数：[分数/等级]
- 上课参与情况：[描述]
- 对各科目的态度：[描述]

【社会脉络】
- 家庭状况：[简述]
- 课后学习环境：[描述]
- 特殊背景：[如新住民子女、原住民、身心障碍等]

请分析并产出：
1. 学生的优势能力
2. 需要支援的领域
3. 适合的学习方式
4. 教学策略建议
5. 需要注意的敏感议题
```

### 学习风格分析
```
请根据以下资料分析学生的学习风格：

【行为观察】
- 听讲时的行为：[描述]
- 做笔记的习惯：[描述]
- 小组讨论表现：[描述]
- 实作活动表现：[描述]

【学习偏好自陈】
学生表示喜欢的学习方式：[描述]
学生觉得困难的学习方式：[描述]

【作业/测验表现】
- 选择题 vs 申论题：[比较]
- 口头报告 vs 书面报告：[比较]
- 图表题 vs 文字题：[比较]

请提供：
1. 学习风格类型判定
2. 适合此风格的教学策略
3. 帮助学生适应不同学习情境的建议
4. 多元评量方式建议
```

### 特殊需求学生轮廓
```
请协助建立这位特殊需求学生的学习轮廓：

【鉴定资料】
特殊需求类型：[学习障碍/情绪障碍/ADHD/资优等]
鉴定报告摘要：[重点摘录]

【学习表现】
- 优势科目：[科目与表现]
- 困难科目：[科目与困难描述]
- 特殊学习需求：[描述]

【适应行为】
- 课堂适应：[描述]
- 同侪互动：[描述]
- 情绪调适：[描述]

【目前支援】
- 资源班服务：[有/无，内容]
- 特教助理：[有/无]
- 其他支援：[列举]

请提供：
1. IEP 目标建议
2. 课堂调整策略
3. 评量调整建议
4. 亲师沟通要点
5. 转衔准备建议
```

## 偏乡学生轮廓特别考量

### 文化敏感度
- 尊重原住民文化认同
- 理解新住民家庭处境
- 避免以都会标准评判

### 资源限制认知
- 理解家庭支援可能有限
- 考量学习环境差异
- 发掘在地优势资源

### 优势观点
- 发现学生的韧性
- 看见文化智慧
- 连结在地知识

## 伦理考量

### 资料保护
- 个资保护法规遵循
- 敏感资料加密储存
- 存取权限控管

### 使用原则
- 轮廓用于支援而非标签
- 避免预设偏见
- 定期更新避免固化
- 学生/家长知情同意
