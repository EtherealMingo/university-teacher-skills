# 学习分析与评量设计参考

> **Goal**：为教师提供「评量设计 + 数据分析」双视角的方法框架——素养导向评量四要素、
> 学习分析四层框架、结构化同侪互评机制、多维度学生轮廓，支撑数据驱动的教学决策。

## 参考文档

- `references/competency-based-assessment.md` — 素养导向评量：强调真实情境、跨领域整合与高层次思考的评量设计，评估学生在真实情境中运用知识解决问题的能力。
- `references/learning-analytics.md` — 学习分析技术：收集、分析与诠释学习历程数据的四层框架（描述性→诊断性→预测性→处方性），用于学习预警与教学决策优化。
- `references/peer-assessment.md` — 同侪互评机制设计：结构化评分规准（Rubric）、评量者训练与品质保证机制，提升互评信效度并减轻教师负担。
- `references/student-profiling.md` — 学生学习轮廓分析：整合认知能力、学习风格、动机态度、社会背景等多维度资讯，支援个人化教学与辅导分组。
