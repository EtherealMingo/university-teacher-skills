# AI 教案产生器 (AI Lesson Plan Generator)

## 技能描述
运用 AI 快速生成符合教学目标、学生需求与课纲标准的教案，大幅减轻教师备课负担。

## 适用情境
- 教师快速备课
- 代课教师应急
- 新手教师学习教案设计
- 跨领域/创新课程设计
- 偏乡教师身兼多科教学

## 教案结构框架

### 标准教案要素
```
┌─────────────────────────────────────┐
│           教案基本资讯              │
├─────────────────────────────────────┤
│ 科目 │ 单元 │ 年级 │ 节数 │ 设计者 │
├─────────────────────────────────────┤
│           学习目标                  │
│ • 认知目标 (知识理解)               │
│ • 情意目标 (态度价值)               │
│ • 技能目标 (实作能力)               │
├─────────────────────────────────────┤
│           教学流程                  │
│ • 引起动机 (5-10分钟)               │
│ • 发展活动 (25-30分钟)              │
│ • 综合活动 (5-10分钟)               │
├─────────────────────────────────────┤
│           评量设计                  │
│ • 形成性评量                        │
│ • 总结性评量                        │
├─────────────────────────────────────┤
│           教学资源                  │
│ • 教材教具                          │
│ • 数位资源                          │
└─────────────────────────────────────┘
```

## 提示词范本

### 完整教案生成
```
请生成一份完整的教案：

【基本资讯】
科目：[科目名称]
单元名称：[单元名称]
适用年级：[年级]
教学节数：[节数]
学生人数：[人数]

【课纲对应】
学习领域：[领域]
核心素养：[素养代码与内容]
学习表现：[表现代码与内容]
学习内容：[内容代码与内容]

【特殊需求】
- 学生程度：[描述]
- 可用设备：[设备清单]
- 特殊考量：[如偏乡、原住民文化融入等]

请包含：
1. 具体可评量的学习目标
2. 详细的教学流程（含时间分配）
3. 师生互动设计
4. 差异化教学策略
5. 多元评量方式
6. 学习单/讲义设计
7. 板书/简报重点规划
```

### 快速备课版
```
我需要快速备课，请帮我：

科目：[科目]
主题：[主题]
时间：[分钟]
重点：[1-3个核心概念]

请给我：
1. 简洁的教学流程
2. 3个引起动机的开场方式
3. 5个检核学生理解的提问
4. 1个简单的课堂活动
```

### 在地化教案设计
```
请设计一份融入在地文化的教案：

科目：[科目]
单元：[单元]
学校所在地：[地区/部落名称]
在地特色：[当地产业、文化、自然环境]
学生背景：[族群组成、语言使用状况]

请设计：
1. 运用在地素材的学习情境
2. 连结学生生活经验的教学活动
3. 融入本土语言的学习机会
4. 邀请社区资源参与的可能性
```

### 跨领域教案设计
```
请设计一份跨领域统整教案：

主题：[主题名称]
涵盖领域：[列出 2-4 个学习领域]
年级：[年级]
总节数：[节数]

请设计：
1. 各领域的学习内容如何整合
2. 跨领域的学习目标
3. 统整性的学习任务
4. 各领域教师的协作方式
5. 学生成果展现形式
```

## AI 教案生成最佳实践

### 有效的提示技巧
1. **具体明确**：提供清楚的年级、时间、目标
2. **情境脉络**：说明学生背景与学习环境
3. **限制条件**：说明可用资源与限制
4. **参考范例**：提供期望的教案风格或范例
5. **迭代修正**：逐步要求 AI 调整特定部分

### 品质检核清单
- [ ] 学习目标具体可评量
- [ ] 教学活动符合学生认知发展
- [ ] 时间分配合理可行
- [ ] 评量与目标相对应
- [ ] 差异化需求有被考量
- [ ] 资源需求可取得

## 不同 AI 工具的特色

| AI 工具 | 优势 | 适用场景 |
|---------|------|---------|
| GPT-4 | 创意发想、多样性 | 活动设计、引起动机 |
| Gemini | 即时搜寻、多模态 | 结合时事、图表生成 |
| Copilot | Office 整合 | PPT、学习单制作 |
