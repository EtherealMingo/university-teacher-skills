# 专题导向学习 (Project-Based Learning, PBL)

## 技能描述
设计以真实问题为核心的专题式学习活动，透过长期、跨领域的探究历程，培养学生问题解决、团队合作、自主学习与创意思考等21世纪关键能力。

## 适用情境
- 跨领域统整课程设计
- 校订必修/选修课程规划
- 弹性学习时间活动设计
- 自主学习专题指导
- STEAM 教育整合

## 专题设计流程

### 专题发展阶段
```
启动阶段          探究阶段          产出阶段
   │                 │                 │
   ▼                 ▼                 ▼
┌──────┐       ┌──────────┐      ┌──────────┐
│ 驱动 │  →    │ 资料搜集 │  →   │ 成果制作 │
│ 问题 │       │ 分析整合 │      │ 公开发表 │
└──────┘       └──────────┘      └──────────┘
   │                 │                 │
   ▼                 ▼                 ▼
 激发动机         建构知识         展现学习
 形成小组         发展技能         反思成长
```

### 时程规划建议
| 专题规模 | 建议时长 | 适用情境 |
|----------|----------|----------|
| 微专题 | 1-2周 | 单一单元延伸 |
| 短期专题 | 3-4周 | 段考后统整 |
| 中期专题 | 1-2个月 | 跨领域课程 |
| 长期专题 | 1学期 | 校订课程 |

## 提示词范本

### PBL 专题设计
```
请设计一个专题导向学习(PBL)专题：

【基本资讯】
年级：[年级]
涵盖领域：[列出整合的科目/领域]
专题时长：[周数/节数]
学生人数：[人数]
分组方式：[个人/小组，每组人数]

【驱动问题】
我想以这个问题/议题为核心：[描述问题或议题]
或请帮我设计驱动问题

【真实情境】
希望连结的真实世界脉络：[社区问题/社会议题/职业情境]

【学习目标】
希望学生学到：
- 学科知识：[列举]
- 核心能力：[如：问题解决、团队合作、批判思考]

【资源条件】
- 可用设备：[列举]
- 可连结的社区/外部资源：[列举]
- 经费限制：[有/无，金额]

请设计：
1. 精炼的驱动问题
2. 专题阶段规划（含各阶段目标与活动）
3. 各阶段教师鹰架设计
4. 形成性评量检核点
5. 最终成果形式建议
6. 评分规准（Rubric）
7. 专题发表形式建议
```

### 驱动问题设计
```
请帮我设计 PBL 驱动问题：

【主题领域】
相关学科：[科目]
核心概念：[概念]
希望探讨的议题：[议题方向]

【学生背景】
年级：[年级]
先备知识：[描述]
学生兴趣：[描述]

【在地连结】
学校/社区特色：[描述]
可运用的在地资源：[列举]

【设计原则偏好】
- 开放程度：[高度开放/适度引导/结构化]
- 难度层次：[挑战型/标准型/入门型]

请提供：
1. 3-5 个驱动问题选项
2. 各问题的探究方向分析
3. 可发展的子问题
4. 适合的成果形式
5. 建议的专题时长
```

### 专题历程评量
```
请设计 PBL 专题的历程评量机制：

【专题资讯】
专题名称：[名称]
专题时长：[周数]
分组方式：[小组/个人]

【评量目的】
希望评估：
- 学科学习：[列举重点]
- 过程技能：[如：资料搜集、团队合作]
- 态度情意：[如：积极度、反思能力]

【评量者】
- 教师评量：[比重%]
- 同侪互评：[比重%]
- 自我评量：[比重%]

请设计：
1. 各阶段检核点与评量工具
2. 小组合作评量表
3. 个人贡献评估机制
4. 学习历程档案架构
5. 最终成果评分规准
6. 反思引导问题
```

## 教师角色转换

### 从讲授者到促进者
```
传统教学               PBL 教学
   │                     │
教师主导    →    学生主导
知识传递    →    探究引导
标准答案    →    多元解方
个人竞争    →    团队合作
纸笔测验    →    成果展现
```

### 鹰架提供时机
| 情境 | 鹰架类型 | 具体策略 |
|------|----------|----------|
| 专题启动 | 动机鹰架 | 真实案例、专家分享 |
| 探究卡关 | 认知鹰架 | 提问引导、资源提供 |
| 合作冲突 | 社会鹰架 | 角色分工、协调策略 |
| 成果制作 | 技术鹰架 | 工具教学、范例展示 |

## 常见挑战与对策

| 挑战 | 对策 |
|------|------|
| 时间不足 | 善用弹性时间、跨领域协作 |
| 学生程度差异 | 差异化任务、异质分组 |
| 小组搭便车 | 个人责任机制、历程评量 |
| 偏离学科目标 | 明确对应课纲、检核点设计 |
| 成果品质不一 | 批判修正机制、同侪互评 |

- 运用线上专家咨询
