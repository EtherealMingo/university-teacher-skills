# 差异化教学策略 (Differentiated Instruction)

## 技能描述
协助教师针对不同学习程度、风格与需求的学生，设计多层次的教学内容与评量方式，实现因材施教。

## 适用情境
- 班级学生程度差异大
- 偏乡混龄/混班教学
- 特殊需求学生融合教育
- 资优生与学习落后生并存的课堂

## 差异化教学三要素

### 1. 内容差异化 (Content)
依学生准备度调整教材深度与广度

| 程度 | 内容设计 | 支援方式 |
|------|---------|---------|
| 基础 | 核心概念、具体实例 | 图解、多媒体、步骤拆解 |
| 中等 | 概念应用、问题解决 | 引导式提问、范例演练 |
| 进阶 | 延伸探究、跨领域连结 | 开放性任务、自主学习 |

### 2. 过程差异化 (Process)
依学生学习风格调整学习活动

```
视觉型学习者 → 图表、心智图、影片
听觉型学习者 → 讲述、讨论、播客
动觉型学习者 → 实作、游戏、角色扮演
读写型学习者 → 阅读、笔记、书面报告
```

### 3. 成果差异化 (Product)
依学生优势提供多元评量选择

- 书面报告 / 口头简报
- 海报 / 数位作品
- 实作演示 / 影片制作
- 小组合作 / 个人作业

## 提示词范本

### 设计差异化教案
```
请帮我设计一份差异化教案：

科目：[科目名称]
单元：[单元名称]
年级：[年级]
班级人数：[人数]
学生程度分布：
- 高程度：约 [%] 学生
- 中程度：约 [%] 学生
- 基础程度：约 [%] 学生

请设计：
1. 三个难度层次的学习目标
2. 差异化的学习活动设计
3. 分层教材或学习单
4. 多元评量方式
5. 教师课堂实施流程建议

特殊考量：[如：班上有原住民学生、新住民子女]
```

### 生成分层学习单
```
请为以下主题生成三个难度的学习单：

主题：[主题名称]
学习目标：[具体目标]

基础版需求：
- 以填空、选择题为主
- 提供较多提示与鹰架
- 题目数量适中

进阶版需求：
- 包含应用与分析题
- 减少提示
- 增加思考性问题

挑战版需求：
- 开放式问题
- 跨领域连结
- 创意发挥空间
```

### 设计弹性分组策略
```
我的班级有以下学生类型：

1. 学习超前学生：[人数]
2. 达标学生：[人数]
3. 需要补强学生：[人数]
4. 特殊需求学生：[类型与人数]

本周教学主题：[主题]
授课时间：[节数]

请建议：
1. 如何进行弹性分组
2. 各组的学习任务分配
3. 教师在各组间的时间分配
4. 如何确保所有学生都达成基本学习目标
```

## 偏乡实施策略

### 师资有限的应对
- 善用数位工具进行自学分组
- 培训学生小老师制度
- 设计自我检核机制
- 运用远距资源（线上志工、大学生辅导）

### 资源有限的应对
- 善用开放教育资源 (OER)
- 设计低科技的差异化活动
- 利用在地素材设计教材
- 社区资源整合运用

## AI 辅助差异化教学

### 诊断工具
- AI 前测分析学生起点行为
- 自动分类学生学习风格
- 即时追踪学习进度

### 内容生成
- 自动生成不同难度的教材
- 客制化练习题目
- 多语言/多模态内容转换

### 回馈机制
- 即时批改与建议
- 个人化学习建议
- 教师教学建议报告
