# SEL 教学活动设计 (Social-Emotional Learning Activity Designer)

## 技能描述

基于 CASEL 架构与控制价值理论（CVT），协助教师设计融入课堂的社会情绪学习（SEL）活动，培养学生的自我觉察、自我管理、社会觉察、人际技巧与负责任决策能力，同时提升学习成效与情绪调节能力。

## 适用情境

- **学科融入 SEL**：将情绪学习自然融入国语、数学、自然等学科教学中
- **翻转教室情绪支持**：在翻转教室或分组讨论时加入情绪检视与正向回馈机制
- **情绪调节教学**：教导学生辨识情绪、管理压力、调节负面情绪的具体策略
- **人际互动训练**：培养同理心、有效沟通、冲突解决等社交技巧
- **班级经营优化**：建立情绪安全的教室文化，降低冲突、提升归属感
- **学习动机提升**：透过自我效能、目标设定等策略增强学习动机
- **偏乡应用**：适合资源受限环境，不需额外教材，善用对话与活动

```
├─────────────────────────────────────┤

│    └─ 情绪识别、优势认识、自信      │
│                                      │
│ 2. 自我管理 (Self-Management)       │
│    └─ 情绪调节、压力管理、目标设定  │
│                                      │
│ 3. 社会觉察 (Social Awareness)      │
│    └─ 同理心、观点取替、尊重多元    │
│                                      │
│ 4. 人际技巧 (Relationship Skills)   │
│    └─ 沟通、倾听、合作、冲突解决    │
│                                      │

```

【设计需求】

2. **当下调节策略**（情绪发生时）
   [例如：深呼吸技巧、情绪命名、暂停冷静、重新框架]

3. **事后反思策略**（事件后）
   [例如：情绪日志、同侪分享、学习迁移]

针对每个策略，请提供：

- **练习活动**：学生如何练习此策略
- **视觉提示卡设计**：描述可张贴在教室的提示卡内容（文字 + 图示建议）

  2. 找到 4 个你听到的声音
  3. 找到 3 个你能碰触的东西
  4. 找到 2 个你闻到的气味
  5. 找到 1 个你喜欢自己的地方

- 练习活动：课堂中模拟紧张情境，全班练习此策略
- 视觉卡：[简笔画图示：眼睛看、耳朵听、手触摸、鼻子闻、心形（喜欢自己）]

请提供：
1. 3-5 个具体策略（含完整资讯）
2. 教师实施手册（如何教导、常见问题）
3. 学生策略卡设计（可印制发给学生）

### 💬 Talk Moves 对话促进活动

设计基于 Talk Moves 的课堂讨论活动，培养学生的倾听与沟通能力：

【讨论主题】
- 学科：[例如：社会科]
- 主题：[例如：环境保护的重要性]
- 年级：[例如：国小六年级]
- 时间：[例如：20 分钟讨论时间]

【Talk Moves 策略应用】
请在活动设计中融入以下策略：

1. **重述 (Revoicing)**：“你的意思是...对吗？”
2. **追问 (Pressing)**：“可以说更多吗？为什么你这样想？”
3. **连结 (Adding On)**：“谁可以补充 OOO 的想法？”
4. **澄清 (Clarifying)**：“可以用自己的话再说一次吗？”
5. **要求证据 (Using Evidence)**：“你的证据是什么？哪里看到的？”

请设计：

1. **讨论前准备**
   - 暖身活动（建立安全讨论氛围）
   - Talk Moves 快速复习（视觉海报）

2. **讨论流程设计**
   - 开场提问（开放式问题）
   - 小组讨论（4-5 人，10 分钟）
   - 全班分享（10 分钟）

3. **教师提问脚本**
   提供至少 5 个教师提问范例，标示使用哪种 Talk Move：
   - “小明刚才提到环境保护很重要，小华，你可以用自己的话说说小明的想法吗？”[澄清]
   - “小美，你为什么认为减少塑料袋很重要？可以多说一点吗？”[追问]
   - （依此类推...）

4. **学生对话框架**（sentence starters）
   提供学生可使用的句型卡：
   - “我同意 ___ 的想法，因为...”
   - “我想补充 ___ 说的...”
   - “我的证据是...”
   - “我有不同的看法，我认为...”

5. **观察评量指标**
   教师如何观察学生的对话品质：
   - [ ] 学生能主动发言
   - [ ] 学生回应时有连结他人想法
   - [ ] 学生能提供证据支持论点
   - [ ] 学生能尊重不同意见

请提供完整的 Talk Moves 讨论活动设计。

### 🎯 SMART 目标设定工作坊

设计协助学生设定学习目标的工作坊活动：

【工作坊资讯】
- 适用情境：[例如：学期初、专案开始前、期中检讨]
- 目标对象：[例如：国中七年级]
- 活动时长：[例如：45 分钟]

【SMART 目标框架】
- **S**pecific（具体的）：目标明确，非模糊笼统
- **M**easurable（可测量的）：可量化，知道何时达成
- **A**chievable（可达成的）：具挑战但不过度困难
- **R**elevant（相关的）：与个人学习需求相关
- **T**ime-bound（有期限的）：设定明确达成时间

请设计工作坊活动，包含：

1. **SMART 概念教学**（10 分钟）
   - 讲解 SMART 五要素
   - 提供好目标 vs 不好目标对比范例
     - 不好的目标：“我要更努力”（太模糊）
     - 好的目标：“我要在这学期内，每周完成 5 次数学练习题，期末考数学成绩进步 10 分”（符合 SMART）

2. **目标设定引导单**
   设计学生填写的工作单，包含以下提问：
   - 你想改善什么学习领域？（学科、技能、态度）
   - 具体来说，你想达成什么？（Specific）
   - 你如何知道自己达成了？用什么测量？（Measurable）
   - 这个目标对你来说是可达成的吗？需要什么资源？（Achievable）
   - 为什么这个目标对你重要？（Relevant）
   - 你要在什么时候达成？（Time-bound）

3. **自我监控工具**
   - 每周检核表（我本周做了什么朝目标前进？）
   - 进度视觉化（如：进度条、阶梯图）
   - 反思问题（遇到什么困难？如何克服？）

4. **庆祝与调整机制**
   - 达成目标的庆祝方式
   - 未达成时如何调整目标（不责备，而是学习）

5. **后续追踪计划**
   教师如何定期与学生检视目标进度（每周？每两周？）

请提供完整的 SMART 目标设定工作坊设计。

## SEL 每日实践策略

| 时机 | SEL 策略 | 实施方式 | 所需时间 |
|------|---------|---------|---------|
| 课堂开始 | 情绪检视 | 情绪温度计、心情颜色卡 | 2 分钟 |
| 小组讨论 | Talk Moves | 鼓励重述、追问、连结 | 融入讨论 |
| 给予回馈 | 先肯定再建议 | “我看到你...（优点），建议可以...” | 融入回馈 |
| 转换活动 | 冥想呼吸 | 一分钟深呼吸，专注当下 | 1 分钟 |
| 课堂结束 | 正向结语 | “今天你帮助了谁？”“你为自己骄傲的是？” | 3 分钟 |

## SEL 融入原则

### ✅ 实施建议
- 将 SEL 自然融入学科，非额外课程或负担
- 教师自身示范情绪调节与社交技巧（身教）
- 创建情绪安全的教室文化（无批判、可犯错）
- 持续而非单次活动（养成习惯）

### ✅ 偏乡友善实践
- 不需昂贵教材，善用对话、活动、同侪支持
- 善用在地资源与社区文化（长辈智慧、传统价值）
- 小班级优势：更多个别关注与支持
- 线上资源补充（免费 SEL 活动资源网站）

### ✅ 评量考量
- 关注过程而非单一结果（成长导向）
- 多元评量：观察、自评、同侪互评、反思日志
- 保护学生隐私与尊严（不公开比较情绪能力）
- 给予成长型回馈（强调进步与努力）
