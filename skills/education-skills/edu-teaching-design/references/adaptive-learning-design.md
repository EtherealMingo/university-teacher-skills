# 自适应学习设计 (Adaptive Learning Design)

## 技能描述
协助教师与课程设计者建构自适应学习系统，根据学生的学习表现、风格与需求，动态调整学习内容与路径。

## 适用情境
- 设计线上学习平台的自适应机制
- 规划差异化教学的学习路径
- 建构个人化学习推荐系统
- 偏乡教育资源有限环境下的适性化设计

## 核心概念

### 学习路径模型
```
┌─────────────┐
│  诊断评估   │ ← 前测/学习风格测验
└──────┬──────┘
       ↓
┌─────────────┐
│  能力分级   │ ← 初级/中级/进阶
└──────┬──────┘
       ↓
┌─────────────┐
│  内容推荐   │ ← 依程度推送教材
└──────┬──────┘
       ↓
┌─────────────┐
│  即时回馈   │ ← 答题正确率/学习时间
└──────┬──────┘
       ↓
┌─────────────┐
│  路径调整   │ ← 动态调整难度与内容
└─────────────┘
```

### 自适应参数设计

| 参数类型 | 说明 | 资料来源 |
|---------|------|--------|
| 认知程度 | 学生目前的知识水平 | 测验成绩、答题表现 |
| 学习速度 | 完成学习单元的速度 | 学习时间纪录 |
| 学习风格 | 视觉/听觉/动手操作 | 学习风格量表 |
| 错误模式 | 常见的错误类型 | 答题分析 |
| 参与度 | 学习投入程度 | 登入频率、完成率 |

## 提示词范本

### 设计自适应学习单元
```
请帮我设计一个自适应学习单元：

主题：[学习主题]
学科：[科目名称]
目标对象：[年级/程度]
预计学习时间：[时间]

需求：
1. 设计 3 个难度等级的学习内容
2. 定义各等级的进入条件与晋升标准
3. 设计形成性评量问题（每等级 3-5 题）
4. 规划学习路径的分支逻辑
5. 设计即时回馈机制

特殊需求：[如：适合偏乡低带宽环境]
```

### 分析学生学习数据
```
请分析以下学生学习数据，并提供自适应建议：

学生资料：
- 前测成绩：[分数]
- 学习时间：[时长]
- 答题正确率：[百分比]
- 错误题型分布：[类型列表]

请提供：
1. 学生目前能力诊断
2. 建议的学习路径
3. 需要补强的概念
4. 推荐的学习资源类型
```

## 实作考量

### 偏乡环境适配
- 支援离线学习模式
- 低带宽友善的内容格式
- 多装置相容（手机/平板/旧电脑）
- 本土语言/方言界面选项

### 教师端支援
- 学生学习进度仪表板
- 班级整体表现分析
- 预警系统（学习落后提醒）
- 教学调整建议
