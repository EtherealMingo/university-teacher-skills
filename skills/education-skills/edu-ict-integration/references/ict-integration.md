# ICT 融入教学 (ICT Integration in Education)

## 技能描述
系统性地将资讯与通讯科技 (ICT) 融入各学科教学，提升学习效果、培养学生数位素养，并因应不同教学情境选择适切的科技工具。

## ICT 融入教学模型

### SAMR 模型
```
┌─────────────────────────────────────────────────────┐
│                    转化 (Transformation)              │
├─────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────┐   │
│  │ 重新定义 (Redefinition)                      │   │
│  │ 创造以前不可能的全新任务                      │   │
│  │ 例：学生与国际伙伴协作专题、VR 实地考察       │   │
│  └─────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────┐   │
│  │ 修正 (Modification)                          │   │
│  │ 科技允许任务的显著重新设计                    │   │
│  │ 例：协作文件即时编辑、互动式简报回馈          │   │
│  └─────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────┤
│                    增强 (Enhancement)                 │
├─────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────┐   │
│  │ 增益 (Augmentation)                          │   │
│  │ 科技作为工具替代品并增加功能                  │   │
│  │ 例：数位笔记可搜寻、电子白板可存取回顾        │   │
│  └─────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────┐   │
│  │ 替代 (Substitution)                          │   │
│  │ 科技直接替代传统工具，无功能改变              │   │
│  │ 例：打字替代手写、PDF 替代纸本                │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

### TPACK 架构
```
                     ┌─────────────┐
                     │   TPACK     │
                     │  整合知识   │
                     └──────┬──────┘
                            │
         ┌──────────────────┼──────────────────┐
         │                  │                  │
         ↓                  ↓                  ↓
   ┌──────────┐      ┌──────────┐      ┌──────────┐
   │   TK     │      │   PK     │      │   CK     │
   │ 科技知识 │      │ 教学知识 │      │ 学科知识 │
   └──────────┘      └──────────┘      └──────────┘

   TK: 了解各种科技工具的功能与操作
   PK: 掌握教学方法与策略
   CK: 精通学科专业内容
   TPACK: 知道如何运用适当科技，以有效的教学法传递学科内容
```

## ICT 工具分类

### 教学呈现工具
| 工具类型 | 代表工具 | 教学应用 |
|----------|----------|----------|
| 简报软件 | PowerPoint, Keynote, Canva | 课程讲述、概念说明 |
| 电子白板 | Jamboard, Miro, Whiteboard.fi | 即时板书、协作讨论 |
| 萤幕录制 | OBS, Loom, Screen-cast-O-Matic | 教学影片制作 |
| 互动简报 | Mentimeter, Slido, Pear Deck | 即时回馈、投票 |

| 协作文件 | Google Docs, Office 365 | 共笔、小组报告 |
| 专案管理 | Trello, Notion, Padlet | 专题进度管理 |
| 虚拟教室 | Google Classroom, Teams | 课程管理 |
| 视讯会议 | Zoom, Meet, Teams | 远距/混成教学 |

| 学习历程 | Seesaw, FreshGrade | 学习档案 |

| 工具类型 | 代表工具 | 教学应用 |

## 提示词范本

### ICT 融入教学设计
```
请帮我设计一堂融入 ICT 的课程：

【课程资讯】
科目：[科目]
单元：[单元名称]
年级：[年级]
节数：[节数]
学习目标：[列出]

【现有设备】
- 教师端：[设备清单]
- 学生端：[设备清单]
- 网络环境：[描述]

【SAMR 目标层次】
希望达到：[ ] 替代 [ ] 增益 [ ] 修正 [ ] 重新定义

【特殊需求】
- 需要离线可用
- 需要操作简单
- 需要免费工具
- 其他：[说明]

请设计：
1. 推荐的 ICT 工具组合
2. 详细的教学流程（含科技使用时机）
3. 学生操作指引
4. 备案（科技故障时）
5. TPACK 分析说明
```

### 数位工具选用评估
```
请帮我评估以下数位工具是否适合我的教学需求：

【教学需求】
目的：[要达成的教学目标]
对象：[学生年龄/程度]
使用频率：[多久使用一次]
情境：[课堂/回家/小组]

【评估工具】
工具名称：[名称]
工具网址：[URL]

【评估面向】请针对以下面向评估：
1. 学习效益：对学习目标的帮助程度
2. 易用性：师生上手难度
3. 相容性：与现有设备/平台的整合
4. 成本：免费/付费/学校授权
5. 隐私安全：资料保护程度
6. 无障碍：特殊需求学生的使用
7. 偏乡适用：低带宽/离线支援

请提供：
- 各面向评分 (1-5)
- 总体建议（推荐/保留/不推荐）
- 替代工具建议
```

## 偏乡 ICT 融入考量

### 挑战与对策
| 挑战 | 对策 |
|------|------|
| 设备不足 | 轮流使用、BYOD、低科技替代 |
| 网络不稳 | 离线优先工具、预先下载 |
| 师资数位能力 | 简化工具选择、同侪支援 |
| 家庭支援不足 | 校内时间完成、纸本备案 |

### 低科技高效益工具
- QR Code（连结数位资源）
- 简讯/电话提醒
- 离线 App
- 广播教学
- USB 资料传递
