# 偏乡教育平台设计 (Rural Education Platform Design)

## 技能描述
针对偏乡地区的基础设施限制、师资人力不足、学生背景多元等特殊需求，设计适切的数位学习平台与解决方案。

## 适用情境
- 偏乡学校数位学习环境建置
- 低带宽/离线学习解决方案
- 远距教学系统设计
- 混成学习课程规划
- 城乡共学平台开发

## 偏乡教育挑战与对策

### 基础设施挑战
```
问题                          对策
──────────────────────────────────────────────
网络不稳定/带宽低        →   离线优先设计
                              渐进式载入
                              轻量化内容
──────────────────────────────────────────────
设备老旧/不足            →   低配置相容
                              共用设备机制
                              BYOD 支援
──────────────────────────────────────────────
电力不稳定               →   自动储存功能
                              省电模式设计
                              太阳能/行动电源整合
```

### 师资挑战
```
问题                          对策
──────────────────────────────────────────────
教师流动率高             →   完整的教学指引
                              预录优质课程
                              远距专家支援
──────────────────────────────────────────────
一师多科                 →   跨科统整资源
                              AI 备课助理
                              共备社群连结
──────────────────────────────────────────────
数位能力落差             →   直觉化界面
                              陪伴式培训
                              技术支援管道
```

## 平台功能优先级

### 核心功能（必要）
| 功能 | 说明 | 偏乡适配考量 |
|------|------|-------------|
| 内容浏览 | 教材、影片、讲义 | 离线下载、低分辨率选项 |
| 作业缴交 | 上传作业档案 | 压缩上传、延迟容错 |
| 评量测验 | 线上测验 | 离线作答、中断续答 |
| 进度追踪 | 学习进度显示 | 简洁资讯、视觉化 |

### 进阶功能（建议）
| 功能 | 说明 | 偏乡适配考量 |
|------|------|-------------|
| 讨论区 | 师生互动 | 异步为主、文字优先 |
| 同侪协作 | 小组任务 | 弹性配对、角色轮替 |
| 游戏化 | 徽章、排行榜 | 个人进步导向 |
| AI 助教 | 即时问答 | 离线知识库 |

### 管理功能（教师端）
| 功能 | 说明 | 简化需求 |
|------|------|---------|
| 学习仪表板 | 班级概览 | 一页总览 |
| 内容管理 | 教材上传 | 批次操作、范本 |
| 成绩管理 | 评分纪录 | 快速输入 |
| 预警系统 | 落后提醒 | 自动通知 |

## 技术架构建议

### 轻量化架构
```
┌─────────────────────────────────────────┐
│              学生端（PWA）               │
│   • 离线优先  • 轻量化  • 跨平台        │
└─────────────────┬───────────────────────┘
                  │ (网络可用时同步)
┌─────────────────┴───────────────────────┐
│            轻量后端（云端）               │
│   • 静态资源 CDN                         │
│   • API 精简                             │
│   • 资料压缩传输                         │
└─────────────────────────────────────────┘
```

### 离线架构
```
┌─────────────────────────────────────────┐
│              校内服务器                  │
│   • 课程内容快取                         │
│   • 学习纪录暂存                         │
│   • 定期与云端同步                       │
└─────────────────────────────────────────┘
        ↑                           ↑
        │ (校内网络)                │
┌───────┴───────┐         ┌────────┴────────┐
│   电脑教室    │         │    学生平板     │
│   (有线网络) │         │   (WiFi)       │
└───────────────┘         └─────────────────┘
```
