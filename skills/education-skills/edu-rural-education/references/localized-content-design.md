# 在地化内容设计 (Localized Content Design)

## 技能描述
设计符合偏乡学生文化背景、语言习惯与生活经验的学习内容，将全球化的知识与在地脉络相连结，提升学习意义感与参与度。

## 适用情境
- 偏乡学校课程设计
- 原住民族教育
- 新住民子女教育
- 特色课程发展
- 社区学校协作

### 在地化内容层次

| 层次 | 说明 | 范例 |
|------|------|------|
| 表层在地化 | 使用在地素材作为例子 | 用部落农作物讲数学 |
| 结构在地化 | 整合在地知识系统 | 结合原住民历法教自然 |
| 深层在地化 | 从在地观点建构知识 | 以族语思维理解概念 |

## 提示词范本

### 在地化教材设计
```
请帮我将以下教学内容在地化：

【原始内容】
科目：[科目]
单元：[单元名称]
学习目标：[原本的学习目标]
原始教材内容摘要：[摘要]

【在地脉络】
学校所在地：[县市/乡镇/部落]
主要族群：[汉族/原住民族别/客家/新住民等]
在地特色：
- 主要产业：[如农业、渔业、观光]
- 自然环境：[如山区、海边、温泉]
- 文化资产：[如祭典、传统建筑、传统技艺]

【学生背景】
- 语言使用：[中文流利度、母语使用情况]
- 生活经验：[常见的日常活动]
- 文化认同：[对传统文化的态度]

请设计：
1. 在地化的学习情境
2. 连结学生生活经验的例子
3. 融入在地知识的教学活动
4. 运用在地资源的实作任务
5. 社区参与的可能性
```

### 原住民族教育内容设计
```
请设计一份融入原住民族文化的教学内容：

【基本资讯】
科目：[科目]
单元：[单元]
年级：[年级]
族群：[族别，如泰雅族、阿美族]

【课纲要求】
学习表现：[表现内容]
学习内容：[内容要点]

【文化融入方向】
希望融入的文化元素：
- [ ] 族语词汇
- [ ] 传统故事/神话
- [ ] 传统技艺/生态智慧
- [ ] 祭仪/岁时节庆
- [ ] 部落历史/迁移史
- [ ] 当代议题

【资源盘点】
- 可邀请的耆老/文化讲师：[有/无]
- 可运用的部落场域：[列举]
- 既有的族语教材：[列举]

请设计：
1. 文化融入的教学流程
2. 族语词汇学习单
3. 耆老访谈/文化体验活动
4. 跨领域连结可能性
5. 文化敏感度注意事项
```

## 伦理与敏感度

### 文化尊重原则
- 咨询部落/社区意见
- 正确呈现文化内涵
- 避免简化或异国情调化
- 尊重知识产权

### 避免常见问题
- 将原住民文化停留在过去
- 泛原住民化（忽视族群差异）
- 观光化/商品化传统文化
- 未经授权使用祭仪内容
