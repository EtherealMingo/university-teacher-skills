# 质量检查清单与反幻觉规则

## 输出前检查清单

### 事实准确性
- [ ] 元数据（标题、作者、venue、年份、DOI）直接取自所提供的文本
- [ ] 数值结果逐字照抄，不四舍五入、不改述
- [ ] 作者单位取自论文署名区，不猜测

### 来源标注
- [ ] 每条贡献都标注 `[原文声明]` 或 `[模型归纳]`
- [ ] `[原文声明]` 条目带位置引用（章节、图、表或原文引文）
- [ ] `[模型归纳]` 条目写明推理依据

### 不确定性标记
- [ ] 缺失字段标 `[未明确给出]`，不留空、不猜测
- [ ] 歧义信息标 `[不确定]` 并说明原因
- [ ] 被跳过的章节明确注明及原因

### 领域假设检查
- [ ] 论文类型由分类规则（rubric）判定，而非假设
- [ ] 方法模板与判定的论文类型匹配
- [ ] 不给非 AI 论文强加 AI/ML 术语

### 降级输入检查
- [ ] 若降级，头部信息行注明 PDF 质量
- [ ] 不可读内容对应的章节明确跳过
- [ ] 未编造任何内容来填补缺口

## 常见幻觉模式

| 模式 | 错误 | 正确 |
|---------|-------|---------|
| 猜测发表场合 | "发表于 NeurIPS"（文中没有） | `[未明确给出]` |
| 夸大贡献 | 添加论文没有提出的贡献 | 只列论文声称的 |
| 夸大结果 | "在所有基准上达到 SOTA" | 引用具体基准 + 指标 |
| 臆测作者资历 | "计算机视觉专家" | 只陈述论文所写内容 |
| 编造未来工作 | 发明未来方向 | 只引用论文自己的未来工作一节 |
| 补全方法细节 | 猜测架构细节 | 标 `[未明确给出]` |

## 降级 PDF 处理协议

**级别：降级**（部分文字可提取）
1. 头部：`PDF 质量：降级处理 - [具体原因]`
2. 文字可用的章节正常完成
3. 不可用章节：`[该部分文本不可读，已跳过]`
4. 提示用户提供更好来源后可重新分析

**级别：严重降级**（几乎无文字）
1. 头部：`PDF 质量：严重降级 - 仅能提取部分内容`
2. 自动切换到 `quick` 模式
3. 只输出可可靠提取的内容
4. 建议：OCR 工具、从 PDF 阅读器复制粘贴，或使用 arXiv HTML 版本

## 证据绑定格式

```
[原文声明] 提出了 X 方法
证据：Section 3.2，"We propose X, which..."

[模型归纳] 该方法在低资源场景下可能有优势
依据：实验仅在小数据集上测试，作者未明确声明此优势
```
