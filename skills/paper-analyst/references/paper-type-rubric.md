# 论文类型分类规则（Rubric）

分析前先把论文归入**一种**主类型。类型决定套用哪个方法分析模板。

## 类型与指标

### AI/深度学习
需满足 2 项以上指标：
- 出现神经网络、深度学习、transformer、CNN、RNN、GAN、扩散模型
- 在基准数据集上报告 accuracy/F1/mAP/BLEU/perplexity
- 有模型架构图
- 出现 GPU 训练、batch size、学习率等超参数
- 使用标准数据集：ImageNet、COCO、SQuAD、GLUE 等

### 传统算法/理论
需满足 2 项以上指标：
- 有伪代码算法或形式化证明
- 有复杂度分析（O 记号）
- 无神经网络组件
- 定理/引理/证明结构
- 属于优化、图论、组合数学、形式化方法

### 系统/工程
需满足 2 项以上指标：
- 系统架构（组件、接口、协议）
- 指标：吞吐量、延迟、可扩展性、可用性
- 实现细节（语言、框架、部署）
- 与现有系统对比

### 实验/实证
需满足 2 项以上指标：
- 人类被试、用户研究、问卷调查
- 统计分析（p 值、置信区间、效应量）
- 提及 IRB/伦理审批
- 定性或混合方法研究

### 综述/Survey
满足 1 项指标即可：
- 标题含 "survey"、"review"、"overview"、"综述"
- 系统性地评述 20 篇以上论文
- 无原创实验或新方法提出

### 其他/跨学科
当论文横跨多种类型、或不属于以上任何一类时使用。

## 冲突消解

1. 先看摘要中论文自己的表述（"we propose"、"we conduct a user study"）
2. 采用指标更多的类型
3. 打平 → 归入 `其他/跨学科`，并注明两种类型

## 输出格式

```
论文类型：[类型标签]
判断依据：[2-3 个具体指标，引用论文内容]
```
