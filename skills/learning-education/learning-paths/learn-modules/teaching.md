# 教学模块

*当学习者选定课节时由 learn.md 加载。TTS 助手指函数定义在 learn.md 中，本会话内可用。*

全程使用 `session.language` 回复。使用 `session.address` 称呼学习者。

---

## 步骤 2A——加载课节内容

**解析路径（优先级顺序）：**
1. 检查项目根目录是否存在 `./lessons/`（Glob `lessons/**`）。如果存在——使用它。
2. 否则使用设置中的 `course.path`。

**查找文件：**
- 在解析出的路径中 Glob 查找与 $ARGUMENTS 中课号匹配的目录。
- 脚本文件——按顺序尝试：
  1. `{lesson_number}_script.txt`（例如 `0.3_script.txt`）
  2. 回退：`digital-course-script.txt`
- 练习文件——按顺序尝试：
  1. `{lesson_number}_exercises.md`
  2. 回退：`exercises.md`
- 进度文件：`~/skill-tutor-tutorials/progress/lesson-{lesson_number}.md`

按 `[מעבר שקף]` 把脚本切分为若干节。

---

## 步骤 3——开场

问候学习者。说明本课主题和章节数量。

**如果本课存在进度文件：**
告诉学习者他们之前的成绩，并询问是想重新开始，还是直接对已讲过的内容来一次测验。

**从 `~/skill-tutor-tutorials/settings.json` 加载已保存的学习风格：**

- `session.mode` ← `learning_style.mode`（默认：`"standard"`）
- `session.detail_level` ← `learning_style.detail_level`（默认：`2`）

**如果已有保存的风格：** 静默应用——无需提问。在问候语里提一次让学习者知道（例如："按你的设置，我们用 diagnostic 模式、详略档位 2 来上课——随时可以改。"）。

**如果设置中没有 `learning_style`（首次或缺失）：** 明确询问学习者：

> **你想怎么学？**
> - **standard**——我讲完每张幻灯片后问一道题（默认）
> - **diagnostic**——先考我，只教我答错的部分，然后继续
> - **socratic**——用问题引导我；我自己发现答案

再询问详略档位（1 / 2 / 3）。

课后，如果学习者中途改过模式或详略档位，询问：
> "想把这个偏好保存给以后的课吗？"
如果是——更新 `settings.json` 中的 `learning_style`。

**提醒——始终有效：** "任何时候都可以切换模式——只要说 'standard'、'diagnostic'、'socratic'，或'给我讲解' / '考考我' / '引导我'。"

---

**如果 `session.mode == "diagnostic"`：** 跳过步骤 3 其余所有提问——不问已有知识、不提供跳课测验——直接进入 **步骤 3B**。

**否则（standard / socratic）：**

询问他们对本课主题已经了解什么（如果有的话）。

- 如果学习者说已经很熟了（例如 "这个我懂"、"我对这个很熟"、"以前学过"）——提供跳课测验："要不要用一次快速测验证明一下？通过我们就把这课标记为完成、进入下一课。" 如果他们同意，以 `quiz me full` 模式读取 `quiz.md`。如果得分 ≥ 7，保存进度并推荐下一课，而不再教本课。如果得分 < 7，从头开始教学。

使用 `learner_profile.md` 校准深度。对学习者明显已掌握的章节，主动提议跳过。

*（若启用 TTS，朗读问候语）*

---

## 步骤 3B——诊断模式入口

*仅当 `session.mode == "diagnostic"` 时*

在开始任何教学之前：

1. 以 **`quiz me full`** 模式读取 `quiz.md`——对整课进行测验。
2. 评分后，收集**薄弱章节**清单（答错或部分答对的题目）。
3. 告诉学习者：
   > "你得了 X/10。现在我们只过一遍那些不太清楚的主题。"
   （按 `session.language` 适配）
4. 设置 `session.weak_sections` = 与答错题对应的幻灯片索引或主题清单。
5. 转入步骤 4，但**只讲薄弱章节**，使用标准 Journey 格式（按 `session.detail_level` 缩放）。学习者答对的章节直接跳过——最多给一句「这个你已经会了」的确认。
6. 讲完薄弱章节后，针对这些主题提供一次简短的跟进测验（`quiz me` 模式，范围限定为薄弱章节）。
7. 然后进入步骤 5（结课）。

---

## 步骤 4——覆盖每一张幻灯片

**重要：每张幻灯片（按 `[מעבר שקף]` 切分出的每一节）都必须体现在课程输出中。** 绝不静默跳过任何一张。至少要用一句话概括它。

*在 `diagnostic` 模式下——只覆盖 `session.weak_sections`；其余幻灯片各给一句确认即可。*

对每张幻灯片，根据 `session.mode` 选择形式：

---

### 模式：socratic（苏格拉底式）

不先讲解，而是以问题开场：

1. **抛出挑战**——用一句话摆出该幻灯片中的问题或概念，但不揭示答案。例如："你觉得当语言模型收到过长的文本时会发生什么？"
2. **等待**——让学习者回答。先不给提示。
3. **引导而非告知**——如果回答错误或不完整，用苏格拉底式追问回应（一个点拨性的问题，而不是讲解）。最多 2 轮提示。
4. **确认并补全**——一旦他们触达正确思路，予以肯定，并补上他们遗漏的关键细节（最多 2 句）。
5. 进入下一张幻灯片。

节奏由学习者主导。如果他们中途说"直接给我讲吧"，仅对当前这张切换到 Journey 格式，下一张起恢复 socratic。

---

### 模式：standard（默认）

对每张幻灯片，套用按 `session.detail_level` 缩放的 **Journey 格式**：

### 详略档位 1——极简
- 每张幻灯片最多 1–2 句
- **目标仍然是教会**——每句话都要让概念真正落地，而不只是复述。哪怕只有一句，也要讲清*为什么*或*所以呢*。
- 不提问、不给情境例子
- 适合快速复习

### 详略档位 2——标准（默认）
使用完整 Journey 格式：
1. **问题（The problem）**——一句话
2. **洞见（The insight）**——用你自己的话讲 2–3 句，不照抄脚本
3. **在你的情境中（In your context）**——与学习者的项目或真实例子的一个具体联结
4. **提问**——一道思考题；等到回答后再继续

每个块：合计最多 5 句。

### 详略档位 3——完整深度
使用完整 Journey 格式，外加：
- 把洞见扩展到 4–5 句
- 为幻灯片中的关键事实、数字或对比加要点列表
- 如果确实相关，可以加一个脚本之外的「你知道吗」知识点
- 仍然要提问并等待回答

**学习者可以随时切换档位**，说 "detail 1"、"detail 2" 或 "detail 3" 即可。

**学习者可以随时切换学习模式**——说 "standard"、"socratic"、"diagnostic"，或用希伯来语 "הסבר לי" / "הדרך אותי" / "בחן אותי"。从下一张幻灯片起生效。

**回应答案：**
- 答对 → 简短肯定 + 继续
- 部分对/答错 → 给一个提示 → 让他们再试一次 → 然后讲解

*（若启用 TTS，朗读每个讲解块——朗读前去掉 markdown 标记）*

## 实时问答（Living Q&A）

对教学过程中学习者提出的每个问题（非测验题），对话式地回答，然后**静默**追加到 `~/skill-tutor-tutorials/tutorials/lesson-{lesson_number}.md` 的 `## Q&A` 小节：

```
**Q:** [the question]
**A:** [the short answer]
```

不要告诉学习者你正在保存——直接做。

---

## 步骤 5——结课

讲完**最后一节**后，按顺序执行：

1. **快速回顾**——用 2–3 个要点总结整课的关键收获。保持精炼。

2. **练习——从练习文件中呈现。** 逐道过已加载练习文件中的练习：
   - 按原文呈现每道练习——不要改写或替换
   - 等学习者回答后再进入下一道
   - 对需要外部工具的练习（分词器网站、外部 API、画图等）——让学习者去做，带着结果回来。回来后针对他们的发现给反馈
   - 对能在对话中完成的练习——就在这里一起做
   - 对每个答案给出具体反馈：哪里对、缺什么、该想什么
   - 如果学习者卡住了，给一个提示——而不是答案
   - **每道练习完成后**，静默地把学习者的答案追加到 `~/skill-tutor-tutorials/progress/exercises-lesson-{lesson_number}.md`：
     ```
     ## תרגיל [N] — [exercise title]
     **תשובה:** [learner's answer, verbatim or summarized if long]
     **פידבק:** [your feedback in one sentence]
     ---
     ```
     文件不存在就创建。不要告诉学习者你正在保存。

3. **测验或小项目——练习之后只提议一次：**

   - **测验** → 读取 `.claude/commands/learn/quiz.md`
   - **小项目** → 一个用 Claude 在 2–3 轮提示内就能完成的动手小任务（除非课节主题就是某外部工具，否则不用外部工具）
   - **都不要** → 跳到第 4 步。

4. **静默保存进度**——写入 `~/skill-tutor-tutorials/progress/lesson-{lesson_number}.md`：
   ```
   # Progress — Lesson X.Y

   **Completed:** [timestamp]
   **Slides covered:** all [N]
   **Summary:** [2–3 sentence summary of what was taught this session]
   ```
   保留文件中已有的测验成绩。不要告诉学习者你正在保存。然后读取 `.claude/commands/learn/progress.md` 保存完整的会话小结。

*（若启用 TTS，朗读回顾与提议）*

## 教学原则

- **首要目标永远是教会**——详略档位只控制长度与深度，绝不控制「教还是没教」。档位 1 的一句话回答也必须让概念真正「咔哒」一声落地，而不只是点个名。
- 所有输出使用 `session.language`
- 每个讲解块最多 5 句——然后轮到学习者说
- 永远先讲**为什么**，再讲**怎么做**
- 把学习者档案中的项目当作主要例子
- 如果学习者已经会了某节——主动提议跳过
- 直接了当：答案错了就明说——然后帮他们得出正确答案
