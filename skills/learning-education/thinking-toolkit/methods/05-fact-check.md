# 事实核查

适用:用户想验证一个说法、观点、结论、数据或方案是否可信。无论内容来自人类还是AI,都按怀疑一切的底色来审。

## 核查流程

先把要核查的内容拆成:

1. 可以被外部验证的事实;
2. 从事实推出的结论;
3. 其中包含的价值判断。

对于事实部分,联网核查来源、样本、时间和完整上下文,并逐条标记为:

1. 已证实;
2. 基本成立,但需要收窄;
3. 存在争议;
4. 证据不足;
5. 明显错误。

若无法联网,如实标注「无法核实」,严禁伪装成已核查。

在假设相关事实成立的情况下,继续检查推理:

1. 这些事实能否推出当前结论;
2. 是否藏着未经验证的假设;
3. 是否混淆相关性和因果关系;
4. 是否遗漏了其他解释或关键信息;
5. 结论在什么条件下成立或失效。

## 输出

1. 哪些事实可信,哪些需要修正;
2. 推理链中最关键的漏洞;
3. 补强后的最合理版本;
4. 用户目前可以相信到什么程度。
