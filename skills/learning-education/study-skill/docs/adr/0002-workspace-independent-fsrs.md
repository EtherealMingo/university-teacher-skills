# 0002. 独立于工作区的 FSRS 调用

## 状态

已接受（Accepted）

## 背景

生成的学习工作区包含课程、练习、笔记和复习数据。它们
不包含技能的支撑脚本。因此，从工作区通过相对的
`scripts/fsrs/fsrs` 路径调用 FSRS，会依赖 `study init`
并不会创建的文件。

## 决策

先解析已安装 study 技能的目录，然后调用
`<skill-dir>/scripts/fsrs/fsrs`，同时让 `FSRS_STORE` 指向当前
工作区的 `.fsrs/cards.json`。

## 影响

每个工作区只拥有自己的复习数据。调度器实现集中在
已安装的技能中，因此升级和修复对所有工作区生效，
无需复制二进制程序。
