# 0001. 仓库结构

## 状态

已接受（Accepted）

## 背景

study 技能组合了 Markdown 指令、工作区模板、一个 Go FSRS
调度器和一个 Python 目录工具。生成的学习工作区不应需要
携带该技能实现脚本的副本。

## 决策

技能编排保留在根部的 Markdown 文件中，可复用的指引放在
`references/` 下，待复制的起始项目放在 `templates/` 下，可执行的
支撑工具放在 `scripts/` 下。

Go FSRS 二进制程序在已安装的技能目录内构建，并从
工作区通过技能相对路径调用。Python 目录工具保持为独立的 uv
项目，拥有自己的锁文件。

## 影响

智能体和维护者可以独立于支撑工具来理解和演进技能指令。
生成的工作区保持小巧且可移植，而共享工具集中保留在
已安装的技能中。
