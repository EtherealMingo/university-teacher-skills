# 0003. 目录扫描的扩展名归一化

## 状态

已接受（Accepted）

## 背景

书籍收藏常常包含大小写混合的电子书扩展名，以及充满分隔符的
文件名，如 `Classical.Mechanics.PDF`。扫描器应当在大小写敏感的
文件系统上产出完整的目录，并为检索生成可读的标题。

## 决策

通过一次目录遍历发现候选文件，并将
`Path.suffix.lower()` 与受支持的格式集合比对。在转标题格式（title-case）
之前，先归一化文件名主干中的点、下划线和连字符。

## 影响

扫描器能一致地处理常见的电子书库命名风格。格式
识别集中在小写后缀比较上，标题检索也获得了更干净的
词边界。
