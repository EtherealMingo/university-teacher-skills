# 教案与课程教学设计

> **Goal**：把教师脑子里的一门课 / 一节课，变成**可直接上课的教案初稿**（含时间分配、
> 师生活动、设计意图）与**配套课件骨架**；需要时一并给出学期教学大纲与考核方案。
> **产出是初稿** —— 学情数据必须由教师提供，教学目标必须可测，教师按自己班级实际情况调整后才算终稿。

## 何时使用

- 「帮我写个教案」/「明天要讲第 3 章，帮我备一下」
- 「这节课怎么设计」/「这个知识点怎么讲学生才懂」
- 「教学设计怎么写」/「教学比赛要交一份教学设计」
- 「教学大纲怎么做」/「一学期的课怎么排」
- 「学生水平参差不齐怎么教」/「怎么分层布置任务」
- 「教学目标怎么写」/「这个目标算不算可测」
- 「这门课适不适合翻转课堂 / 用 PBL」
- 「这门课怎么考核」/「平时分怎么给」

**不适用**：

| 需求 | 该用哪个 skill |
|---|---|
| 出题、编试卷、随堂小测 | `quiz-generator` |
| 把已有教案做成 PPT 或润色课件 | `lecture-slides` |
| 考后成绩分析、试卷审核 | `exam-pipeline` |
| 教学竞赛示范课 + 评委视角打磨 | `teaching-contest`（本 skill 的增强版） |
| 课堂实时互动、投票题 | `classroom-live` |

### 底座口径转译（必做，不能直接照抄）

`skills/education-skills/edu-teaching-design/` 等 `edu-` 系列底座源自台湾 **108 课纲**口径（学习表现／
学习内容代码、核心素养、领域学习节数），本包已将其译为简体，但**术语体系仍是台湾课纲的**。
本 skill 面向内地高校课堂，引用时**必须转译**，不得把台湾课纲术语直接写进交付物：

| 底座的写法 | 转译成本包的写法 |
|---|---|
| 学习目标（认知／情意／技能） | **知识目标／能力目标／素养目标**三维目标 |
| 核心素养、学习表现代码 | 毕业要求指标点 / 专业人才培养方案对应要求（**不引具体条款号，写「按本专业培养方案」**） |
| 引起动机／发展活动／综合活动 | 导入／核心环节／小结（三段式逻辑保留，名称本地化） |
| 节数（40 分钟一节） | **学时（45 分钟一学时）**，45／90／135 分钟课时结构 |
| 课纲、领域 | 课程教学大纲、开课单位 |
| 偏乡教育策略 | 大班额／基础薄弱班级策略（仅取「师资与资源有限时如何分层」的思路） |

> 转译只改术语与课时口径，**不改教学法内核**（差异化三要素、PBL 七要素、双向细目表照用）。

## 前置信息收集（intake，一次性问完）

按 `INPUT_MODEL.md` 的 `question-batch` 机制，**下面 10 项合并成一次提问**，
不要边做边问、也不要先动手再补问。信息不全时用「安全默认值」继续，并在交付物顶部标注哪些是默认值。

| # | 必问项 | 为什么必须问 | 缺省时的安全默认值 |
|---|---|---|---|
| 1 | **学科 / 专业** | 决定教学法、案例来源、板书形态（工科公式推导 vs 文科文本细读差异极大） | 不设默认，**必须问** |
| 2 | **课程名称** | 出现在教案表头、大纲封面 | `【待补：课程名称】` |
| 3 | **学生层次**（本科几年级／研究生／专科／留学生） | 决定目标认知层次上限与语言难度 | 本科二年级 |
| 4 | **课时长度**（45／90／135 分钟，或一学期总学时） | 决定教学过程环节数与时间分配表 | 45 分钟（1 学时） |
| 5 | **班级规模**（人数区间） | 决定能否小组研讨、互评、分层任务是否可操作 | 40–60 人（大班） |
| 6 | **是否有指定教材**（书名／版次／章节） | 决定教案内容映射到哪一章哪一节；**绝不代教师编造教材名与版次** | `【待补：教材名称/版次/章节】`，教学过程按知识点通用结构写 |
| 7 | **是否双语 / 全英文授课** | 决定板书、术语表、学生材料语言 | 中文 |
| 8 | **是否有课程思政要求** | 决定素养目标里是否单列思政点、是否有指定融入点 | 默认「无硬性要求」，素养目标按专业素养写 |
| 9 | **本节课要讲的具体内容 / 章节** | 教案的核心输入 | 不设默认，**必须问**（若只给了课程名，按课程大纲的下一章顺推并标注） |
| 10 | **学情数据**（前测成绩、先修课完成情况、作业得分分布、已掌握/易错点） | **红线相关**：没有数据不得编造 | 学情分析只写「结构性维度 + `【待补：请教师填入本班实际数据】`」，不填具体百分比 |

补充可问（有则用，无则跳过）：是否有学校/学院的教案模板文件、是否需要配套课件、
是否有教学进度表或校历时间节点、是否有特殊学生（留学生、转专业、重修生）。

**提问模板**（可直接发出）：

```
为了把这份教案做成能直接上课的初稿，麻烦一次性告诉我这几项（缺的直接说「没有」）：
1. 学科/专业：
2. 课程名称：
3. 学生层次（本科几年级/研究生/专科/留学生）：
4. 课时长度（45/90/135 分钟）：
5. 班级规模（大约多少人）：
6. 指定教材（书名、版次、本节课对应章节；没有就说没有）：
7. 是否双语/全英文：
8. 是否有课程思政要求（有的话指定融入点是什么）：
9. 本节课具体讲什么内容/第几章第几节：
10. 学情数据（前测成绩、作业分布、已知薄弱点；没有就说没有，我不替你编）
```

## 工作流

### 阶段零 · 判定任务类型与产出范围

| 教师意图 | 走哪条链 |
|---|---|
| 「写个教案」「这节课怎么设计」 | A 线：单次课教案（阶段一→六 → 八 → 九） |
| 「教学大纲怎么做」「一学期的课怎么排」 | B 线：课程整体设计（阶段七 → 八 → 九），学情与目标部分复用阶段一、二 |
| 「这门课整体设计 + 每节课教案」 | A+B 全线，先 B 后 A（大纲定章节学时，再逐章落教案） |

**动作**：从 intake 答案里抽 5 个字段填成一行「课程指纹」写在草稿顶部：
`学科 | 课程名 | 层次 | 课时 | 规模`。后文所有内容以此为准，中途如需改口径，**回到这一行改，并全局扫一遍**。

**输出**：`draft.md` 顶部的课程指纹行 + 任务类型标记。
**退出条件**：intake 10 项全部有答案或已用默认值标注；任务类型明确。

### 阶段一 · 学情分析（不做数据编造）

**输入**：intake 第 3／5／10 项 + 教师提供的任何成绩表/作业样本。

**动作**：按 `student-profiling.md` 的**認知／情意／社會**三维架子，收束成本 skill 的五栏学情表：

| 维度 | 要写什么 | 数据来源（教师提供才写） |
|---|---|---|
| 起点知识 | 已学先修课、已掌握的核心概念、**具体迷思概念**（如「把分母当成份数而不是每份大小」这种精确描述） | 前测／先修课成绩／教师经验判断 |
| 起点能力 | 已具备的操作/计算/写作/实验技能 | 作业样本、实验报告 |
| 认知与学习风格 | 抽象推理 vs 具象依赖、理论偏好 vs 动手偏好 | 问卷（VARK）／课堂观察 |
| 情感与动机 | 对本课程的兴趣、选课动机（必修／选修／转专业）、自我效能 | 教师描述，**不得替学生下结论** |
| 差异分布 | 三层人数或比例（拓展层／达标层／基础层） | 成绩分布；**无数据则留占位** |

**差异化任务设计**（核心，引用 `differentiated-instruction.md` 三要素 + `k12-lesson-differentiation` 三档法）：

按 **內容（Content）／過程（Process）／成果（Product）** 三要素各做一次分层，产出一张分层任务表：

| 层级 | 目标认知层次 | 任务形态 | 支架（scaffold） | 完成判据 | 评价方式 |
|---|---|---|---|---|---|
| 拓展层 | 评价 / 创造 | 开放任务：给情境与约束，无标准答案 | 只给任务书 + 参考文献线索 | 方案能自证其合理性 | 量规（rubric） |
| 达标层 | 应用 / 分析 | 结构化任务：有明确求解路径 | 示例 + 提示卡 + 关键公式表 | 结果正确且步骤完整 | 量规 + 参考答案 |
| 基础层 | 识记 / 理解 | 填空、选择、模仿性练习、概念图补全 | 分步操作卡 + 模板 + 口诀 + 同伴互助 | 能独立复现核心步骤 | 即时反馈 + 订正 |

**四条硬纪律**（来自 `k12-lesson-differentiation` 与 `k12-check-for-understanding`，转译为高校口径）：

1. **共享内容只写一次**：三档任务必须共用**同一个情境、同一组数据、同一则案例**，只有任务要求不同。
   禁止给基础层换一个简单案例、给拓展层换一个复杂案例 —— 那会让三档内容漂移，教师无法统一讲评。
2. **不用贬义标签**：不写「差生」「基础薄弱」「学困生」，改写具体行为描述
   （「尚不能独立完成多元复合函数求导」，而不是「数学基础差」）。分层表里的层名用**拓展层／达标层／基础层**。
3. **分层不等于减量**：基础层减少的是**抽象度与步骤跨度**，不是知识点覆盖；核心概念所有层都必须拿到。
4. **弹性分组，不做固定标签**：按本节任务临时分组，允许学生自选「我要挑战哪一档」，
   每 2–3 次课允许换档，避免分层变成固化分层。

**输出**：`学情分析` 段落（五维表）+ `分层任务表`（三档）。
**退出条件**：五维中每一维要么有教师提供的数据，要么明确写 `【待补：请教师填入本班实际数据】`；
全篇**没有任何 AI 编造的百分比、人数、成绩**。

### 阶段二 · 三维教学目标撰写（本 skill 最硬的一环）

**输入**：阶段一的分层结论 + intake 第 3／6／8 项。

**动作一 · 套四要素公式**。每条目标必须写全，缺一不可：

```
【行为主体】学生 +【可测行为动词】+【行为条件】+【表现程度】
```

- 行为主体写「学生」或省略主语，**不写「使学生…」「让学生…」「培养学生的…」**
- 可测行为动词见下表；行为条件如「在不查阅资料的情况下」「借助 Python 完成」；
  表现程度如「至少 3 个正确」「准确率 ≥ 80%」「在 200 字内」

**动作二 · 按布鲁姆认知层次选动词**：

| 层次 | 可测动词（用这些） | 典型评价方式 |
|---|---|---|
| 识记 | 说出、列举、默写、标注、指出、识别、写出定义 | 填空、选择、名词解释 |
| 理解 | 解释、概述、举例说明、用自己的话复述、区分、归纳、转述为图表 | 简答、概念图、改述 |
| 应用 | 计算、求解、运用…解决…、操作、演示、按规范实施 | 计算题、实操考核、代码运行 |
| 分析 | 比较、拆解、归因、找出…的原因、判断…属于哪一类、建立…之间的对应关系 | 案例分析、故障诊断、对照表 |
| 评价 | 评判、论证、质疑、选择并说明理由、依据…指出…的局限 | 评述题、方案评审、互评 |
| 创造 | 设计、编写、构建、提出…方案、制作、整合…形成… | 课程设计、项目作品、方案书 |

**动作三 · 扫掉不可测动词**。以下动词**一律不许进目标**，它们无法观测、无法评价：

> 理解、掌握、了解、熟悉、体会、感知、领悟、培养…意识、激发…兴趣、提高…能力、
> 树立…观念、增强…素养、认识到…重要性、初步了解

生成草稿后**必须跑一次机械扫描**（这是可执行的，不是「应该检查一下」）：

```bash
grep -nE "理解|掌握|了解|熟悉|体会|感知|领悟|树立|增强.*意识|培养.*(意识|兴趣|能力)|激发|提高" draft.md
```

命中的每一行都要改写成「动词 + 条件 + 程度」。**改写示例**：

| ❌ 不可测 | ✅ 可测 |
|---|---|
| 理解牛顿第二定律 | 能对给定的 3 个变力情境，写出 F=ma 的矢量表达式并说明各量含义，正确率 ≥ 80% |
| 掌握 Python 列表推导式 | 能独立编写列表推导式完成 5 个数据筛选任务，语法一次通过率 ≥ 4/5 |
| 了解市场营销 4P 理论 | 能列举 4P 各要素并各举 1 个真实企业案例，案例信息与要素对应无误 |
| 培养学生的团队协作意识 | 能在小组任务中承担 1 项明确分工，并按约定时间提交自己负责的部分 |
| 激发学生对古典文学的兴趣 | 能从给定篇目中自主选 1 篇完成 300 字读后感，并说明选择理由 |

**动作四 · 三维目标分列，并建立目标↔环节↔评价的三向对齐**：

- **知识目标**：本节课学生要知道什么、能说出/写出什么（识记、理解层为主）
- **能力目标**：本节课学生能做什么（应用、分析、评价、创造层为主，**必须含至少 1 条高层次**）
- **素养目标**：本节课学生在态度、价值、方法、协作、规范上的可观测表现。
  **有课程思政要求的课时，思政点必须落在这一维**，且必须可测
  （「能在案例讨论中引用『按学校/学院相关规定』"不够；「能结合给定案例写出 200 字论述，指出该技术应用中的 2 个伦理风险点」才够）。
  思政点**只写教师指定的融入点**，教师没指定就不自行发明，留 `【待补：本课程思政融入点】`。

**数量建议**：单次课 3–5 条（每维 1–2 条，总条数不超过 5，否则一节课讲不完）；
一学期课程 6–10 条总目标，章节目标向下分解。

**输出**：三维目标表（每维 1–2 条，每条含动词/条件/程度）。
**退出条件**：`grep` 不可测动词扫描**零命中**；每条目标都能一句话说清「怎么考」；
素养目标与课程思政要求一致（或有占位）。

### 阶段三 · 教学重点与难点

**输入**：阶段二目标 + intake 第 9 项。

**动作**：分两栏写，两者判定标准不同，**不许写成一回事**：

| 项 | 判定标准 | 写法 |
|---|---|---|
| **教学重点** | 由**目标**决定 —— 目标里必须达成的核心概念/技能 | 「XX 的判定条件与适用边界」 |
| **教学难点** | 由**学情**决定 —— 学生已有认知与目标之间的落差，通常是迷思概念、抽象度跳跃、步骤跨度过大 | 「为什么 XX 在 YY 情况下不成立」（并写出学生常见错误表现） |

难点必须**写出破解策略**（与阶段五的教学环节挂钩）：

| 难点 | 学生典型错误表现 | 破解策略 | 落在哪个环节 |
|---|---|---|---|
| 例：复合函数求导的链式法则 | 漏乘内层导数；把内层当常数 | 先用具体数值函数做 3 步放慢演示 → 再抽象成符号形式 → 配对练习 | 核心环节第 2 段（15′） |

**输出**：重点难点表 + 难点破解策略表。
**退出条件**：每条难点都有一条明确的破解策略并已安排到具体环节与时间。

### 阶段四 · 教学方法选型

**输入**：intake 第 2／4／5 项 + 阶段一学情。

**动作**：按下面这张表选**一个主法 + 至多一个辅助法**，不许堆砌（一份 45 分钟教案写五种教学法是废纸）。
选定后写明**为什么选它**和**为什么没选更炫的那个**。

| 教学法 | 适合的内容类型 | 最少课时 | 教师课前准备量 | 学生课外负担 | 最适合的学情 | 主要风险 | 配套考核 |
|---|---|---|---|---|---|---|---|
| **讲授 + 提问**（基线） | 概念定义、公式推导、理论体系铺陈 | 45′ | 低 | 低 | 大班、基础层占比高、先修知识缺口大 | 学生被动、注意力 15 分钟后衰减 | 随堂提问 + 课后练习 |
| **案例教学** | 真实情境决策、实务流程、伦理与法规、管理/医学/法学/商科 | 90′ ≥ | 中高（要选案、要写讨论提纲） | 中（课前读案例） | 学生已有基础理论、缺的是应用判断 | 案例选得不典型 → 讨论散掉；教师忍不住给答案 | 案例分析报告 + 课堂发言 |
| **项目式学习 PBL** | 综合能力、跨章节整合、真实任务产出（设计/开发/调研/作品） | ≥ 1–2 周（微专题），长期 1 学期 | 高（驱动问题设计、里程碑、量规） | 高 | 学生基础较整齐、有自主性、能分组协作 | 搭便车、进度失控、产出浮于表面；**课时不足时硬上 PBL 一定烂尾** | 过程档案 + 中期检查 + 成果答辩 |
| **翻转课堂** | 事实性知识可自学、课堂时间需要留给高阶活动的课程 | 单次课可做，但整门课效果更好 | 高（课前视频/阅读包 + 课中活动设计 + 自学检测） | 高（**课前必须真的学了**） | 学生有自学条件与纪律、小班或中班 | 课前不学 → 课堂活动全塌；**技术只到 SAMR 的「替代」层等于白翻** | 课前自学检测（计入平时分）+ 课中产出 |
| **混合式教学** | 整门课重构：线上知识传递 + 线下实践研讨 | 1 学期 | 很高（平台建课、资源切片、线上线下对齐） | 中高且持续 | 有平台支持、学生设备条件好 | 线上线下一张皮、线上资源无人看 | 线上学习数据 + 线下表现双轨 |

选型说明要点：

- **翻转课堂先过 SAMR 检查**（引用 `ict-integration.md`）：如果「课前看视频」只是把课上讲授录下来
  （Substitution 层），课堂又照旧讲一遍，那就是无效翻转。翻转的合格线是课中任务
  达到 **Modification 及以上**（任务因技术而实质重构，例如线上协作编辑、数据可视化即时反馈）。
- **PBL 先过课时检查**（引用 `project-based-learning.md` 的时程档位）：
  微专题 1–2 周、短期 3–4 周、中期 1–2 月、长期 1 学期。
  单次 45 分钟课**不能**叫 PBL，只能叫「项目的一个环节」或「任务驱动的小活动」。
- **大班（>80 人）**优先「讲授 + 结构化提问 + 出口票」；**小班（<30 人）**才可以上研讨/PBL 为主。

**输出**：教学法选择说明（主法 + 辅助法 + 选型理由 + SAMR/课时合规检查结果）。
**退出条件**：选型在课时与班级规模上**站得住**（有明确的一句话理由反驳「为什么不选更炫的那个」）。

### 阶段五 · 教学过程设计（分环节，时间分配必须算得平）

**输入**：阶段二目标、阶段三难点、阶段四选型、intake 第 4 项课时。

**动作一 · 按课时长度套结构模板**（保留 `lesson-plan-generator.md` 的「导入→发展→综合」三段逻辑，
本地化为「导入→核心环节→小结」，并按 45 分钟学时换算）。

#### 45 分钟（1 学时）标准结构

| 环节 | 时间 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|---|
| 导入（情境/问题/复习） | 5′ | 抛 1 个真实问题或反例，激活先备知识；**不给答案** | 独立思考 1 分钟 + 邻座交流 1 分钟 | 制造认知冲突，指向本节难点 |
| 目标呈现与先备激活 | 3′ | 明示本节 3 条目标与验收方式 | 明确「这节课结束时我能做到什么」 | 目标可见可评 |
| 核心环节（精讲/探究） | 15′ | **拆成 2 段，每段 ≤ 8 分钟**；每段结束有 1 次检核 | 记录、回答检核题、跟做 | 控制注意力衰减，及时纠错 |
| 课堂练习 / 研讨 | 15′ | 分层任务（三档同时下发），巡视，收集 2 个典型错误 | 按档完成任务；拓展层做开放任务 | 应用/分析层目标落地，暴露迷思 |
| 小结与作业布置 | 5′ | 让学生自己说本节 3 个要点（不代说），布置作业并说明评分点 | 口头归纳 + 记录作业 | 学生输出才算学会 |
| 缓冲 | 2′ | 处理设备/提问超时 | — | 时间分配不许卡到 0 |

#### 90 分钟（2 学时连排，含 10 分钟课间）

| 时段 | 环节 | 时间 |
|---|---|---|
| 第 1 学时 | 导入 | 8′ |
| | 核心内容一（精讲 + 即时检核） | 25′ |
| | 即时练习（配对/同桌互检） | 10′ |
| | 缓冲 | 2′ |
| — | **课间休息** | 10′ |
| 第 2 学时 | 回顾（最快 1 道检核题唤醒） | 5′ |
| | 核心内容二 / 难点深挖 | 20′ |
| | 小组任务 / 案例分析 / 实验 | 15′ |
| | 总结、作业布置、出口票 | 5′ |

> 变体（案例课 / 实践课，讲练一体）：情境导入 10′ → 案例发布与分组 10′ → 小组探究 35′ →
> 课间 10′ → 汇报 20′ → 教师点评与总结 10′。

#### 135 分钟（3 学时，45×3 或 90+45）

| 方案 | 结构 |
|---|---|
| **45×3 平推** | 第 1 学时：概念铺垫与核心原理（导入 5′ + 精讲 25′ + 检核 10′ + 小结 5′）<br>第 2 学时：实践/探究/实验（任务说明 5′ + 分组实践 30′ + 中途检核 10′）<br>第 3 学时：汇报、互评与总结（汇报 20′ + 互评 10′ + 教师点评 10′ + 作业与反思 5′） |
| **90 + 45** | 前 90 分钟按上面「90 分钟结构」讲练一体完成主体内容；后 45 分钟做**拓展研讨或随堂测验**（拓展案例 15′ + 研讨 20′ + 总结 10′） |

**动作二 · 时间分配铁律**（自检时逐条过）：

1. **时间总和 = 课长，误差 ≤ 2 分钟**（必须真加一遍，不能目测）。
2. **教师连续讲授不超过 15 分钟**；每 20 分钟至少 1 次**可观测的学生行为**
   （答题、操作、讨论、板书、跑代码）。
3. 每个环节的「设计意图」必须**回指阶段二的某一条目标或阶段三的某一条难点**，
   指不上的环节就是冗余环节，删掉。
4. **难点必须有专门的减速环节**，不能只靠「讲慢一点」。
5. 留 2 分钟缓冲；连排课必须安排课间休息（学生注意力在 45 分钟后显著下降）。

**动作三 · 课中检核与出口票**（引用 `k12-check-for-understanding`）：

- 每个核心环节结束放 **1 道检核题**（共 1–3 道），干扰项要来自阶段一记录的**真实迷思概念**，
  不是随便编错误选项。
- 教师按学生反应**分流**：「都会 → 直接进下一个内容」「一半错 → 再讲一次但换表征（图/数值/类比）」
  「多数错 → 回到前置概念」。这一栏要写进教案，教师才知道拿到数据后干什么。
- 出口票（下课前一题）：用于判断本节目标是否达成，**下一节课的起点由它决定**。

**输出**：教学过程表（环节 × 时间 × 教师活动 × 学生活动 × 设计意图）+ 检核题与分流策略。
**退出条件**：时间加总正确；每个环节设计意图能回指目标/难点；每 20 分钟内有学生行为；
难点有专门环节；课时与教师提供的课时长度一致。

### 阶段六 · 板书设计、作业布置、教学反思

**动作**：

1. **板书设计**：给出黑板的**分区布局**（左：主线结构/知识框架；中：本节核心推导或案例要点；
   右：临时区/学生生成内容、易错点）。写成文字版的板书分区示意 + 主干关键词，
   **不许用空格拼伪表格**（CONVENTIONS §2）。
2. **配套课件骨架**：按教学环节给每页的标题与要点（页数与环节对应，一般 1 环节 2–4 页），
   用于下阶段的 `pptx_kit.py`。
3. **作业布置**（分层 + 可评）：
   - 必做（对应达标层目标）+ 选做（对应拓展层目标，标「挑战」不强制）
   - 每题标注**对应目标编号**与**评分点**，写清提交形式与截止时间
   - 作业量按「课后:课上 ≈ 1:2」估算（45 分钟课留 15–25 分钟课后作业量为宜）
4. **教学反思**：**留空位**，写成带提示语的空白区，由教师课后手写/补填：

```
【教学反思（课后填写，AI 不代写）】
· 目标达成情况：___（对照出口票结果填写）
· 时间分配是否合理：___（哪个环节超时/不够）
· 学生主要迷思：___
· 需要调整的地方：___
```

> **反思必须留空**。AI 代写的反思是假的，且教学检查/教学竞赛会要求教师本人手写内容。

**输出**：板书分区设计 + 课件大纲 + 分层作业 + 空反思表。
**退出条件**：作业每题都有对应目标与评分点；反思区确认为空占位。

### 阶段七 · 课程整体设计（B 线，按需）

**输入**：intake 第 1／2／3／4／6／8 项 + 培养方案（教师提供才用）。

**动作一 · 课程基本信息与课程定位**

课程名、学分/总学时（理论:实验:实践 学时比例）、开课学期、先修/后续课程、
课程在培养方案中的定位（对应哪几项毕业要求）——**不引具体条款号，写「按本专业培养方案」并提示教师核对**。

**动作二 · 课程目标**（6–10 条，全部可测）
沿用阶段二的三维目标公式，按「知识—能力—素养」分组，每条**标注它对毕业要求的支撑关系（教师填）**。

**动作三 · 章节学时分配表**

| 章 | 章节名称 | 学时（理论/实验/实践） | 对应课程目标 | 主要教学法 | 核心难点 | 考核方式 |
|---|---|---|---|---|---|---|
| 1 | | 4/0/0 | 目标 1、2 | 讲授 + 提问 | | 课后作业 |
| 2 | | 2/2/0 | 目标 2、3 | 案例教学 | | 实验报告 |
| … | | | | | | |
| **合计** | | **必须 = 课程总学时** | | | | |

生成后**加总校验**：各章学时之和必须等于 intake 给的总学时（或学校规定的学时数），
不等则必须指出差额并让教师决定加在哪一章 —— 不许悄悄凑数。

**动作四 · 考核方式设计**（引用 `competency-based-assessment.md`，转译为高校成绩构成）

| 考核项 | 占比 | 考核内容 | 对应课程目标 | 认知层次 |
|---|---|---|---|---|
| 平时（出勤/课堂参与/出口票） | 10% | 课堂表现与即时检核 | 全部 | 识记–应用 |
| 作业/实验报告 | 20% | 章节应用任务 | 目标 1–4 | 应用–分析 |
| 期中 | 20% | 前半程知识 + 分析题 | 目标 1–3 | 识记–分析 |
| 期末 | 40% | 综合应用与方案设计 | 目标 2–6 | 应用–创造 |
| 项目/课程设计（有则替代部分期末） | 10% | 过程档案 + 成果 + 答辩 | 目标 3–6 | 分析–创造 |
| **合计** | **100%** | | | |

三条要求：

1. **占比之和必须 = 100%**，且过程性考核（平时 + 作业 + 项目）**建议不低于 40%**
   —— 纯期末一张卷测不出高阶目标。
2. **目标覆盖率检查**：每条课程目标至少被 1 个考核项覆盖；有目标无人考 = 目标虚设，必须补。
   输出一张「目标 × 考核项」覆盖矩阵。
3. **认知层次比例**（引用 `competency-based-assessment.md` 的双向细目表口径，可按课程性质调整）：
   记忆理解 : 应用分析 : 评价创造 ≈ **30% : 50% : 20%**。纯记忆型试卷不适用于能力型课程。

**动作五 · 教学进度与参考资料**
周次/日期、每章学时、作业与测验节点（对齐校历）；
教材 + 参考书目 —— **只写教师提供或公开可核实的教材信息，绝不编造书名、版次、出版社、年份**，
未提供的留 `【待补：参考书目】`。

**输出**：教学大纲初稿（课程信息 / 定位 / 目标 / 章节学时表 / 考核方案 + 覆盖矩阵 / 进度表 / 参考教材）。
**退出条件**：学时加总正确；考核占比加总 100%；每条课程目标有考核项覆盖；
无编造的教材与文献。

### 阶段八 · 产出与自检（走 office-layer）

**输入**：`draft.md`（教案）与 `outline.md`（大纲）已冻结，内容自检通过。

**动作一 · 机械自检**（在冻结前跑，不要凭记忆判断）：

```bash
# 1) 不可测动词扫描（必须零命中）
grep -nE "理解|掌握|了解|熟悉|体会|感知|领悟|树立|激发|提高|增强.*意识|培养.*(意识|兴趣|能力)" draft.md

# 2) 占位符清点（交给教师补齐，不是错误）
grep -n "【待补" draft.md

# 3) 时间数字加总核对（人工或用脚本把所有 “N′” 抽出来相加，与课时长度比对）
grep -oE "[0-9]+′" draft.md
```

```bash
PY="skills/office-layer/.venv/bin/python"

$PY skills/office-layer/scripts/pptx_kit.py inspect --in 课件_....pptx                     # 信息密度自检
```

- `inspect` 报出的 `overdense`（单页正文 >220 字符）**必须拆页**，不是可忽略的提示。
- 课件只放**环节要点与检核题**，不放教案全文；教师讲稿放 `notes`。

**动作四 · 需要时生成 xlsx**：分层任务分配表、目标-考核覆盖矩阵、学时分配表可出 xlsx：

```bash
export MPLCONFIGDIR=/tmp/mplcache && mkdir -p /tmp/mplcache   # 受限环境必需
$PY skills/office-layer/scripts/xlsx_kit.py build --spec grid.json --out 目标考核覆盖矩阵.xlsx
```

**退出条件**：不可测动词零命中；`inspect` 读回的表格数/段落数与预期一致；
pptx 无 `overdense` 页；所有 `【待补】` 已列表告知教师。

### 阶段九 · 交付说明与教师确认

按 `CONVENTIONS.md` §9，交付话术**必须是初稿口吻**，并明确列出教师需要核对的地方：

```
这是初稿，请重点核对三处：
1. 学情分析 —— 里面的分层比例和迷思概念是我按通用规律写的，
   必须换成你班上真实数据（已用【待补】标出）。
2. 时间分配 —— 按你给的 <45/90/135> 分钟排的，实际讲下来如果某个环节会超时，
   告诉我，我帮你重新配平。
3. 教材对应 —— 你指定的教材章节我按 <教师给的章节> 映射的，
   如果进度不一致，把实际范围给我。
另外教学目标我全部改成了可观测动词，你确认一下有没有漏掉必须达成的点。
```

若产出含学生名单/成绩数据，必须加一句（`CONVENTIONS.md` §6）：
**「本文件含学生个人信息，请注意保管；任务结束后请删除中间文件。」**

**退出条件**：教师确认或提出修改；明确记录教师确认了哪几项、改了哪几项。

## 红线

1. **不虚构学情数据**。没有前测成绩、作业分布就不许出现具体百分比、人数、平均分。
   学情分析只写结构性维度 + `【待补：请教师填入本班实际数据】`。
   分层比例若教师未提供，写成「按经验典型分布（拓展:达标:基础 ≈ 2:6:2），**请改为本班实际比例**」。
2. **教学目标必须可测**。交付前 `grep` 不可测动词必须零命中；每条目标都必须能回答「怎么考」。
3. **教案是初稿，不是终稿**。必须显式告知教师按实际班级调整；**不许用「已完成」的口吻交付**。
4. **教学反思必须留空位**，AI 不代写反思（教学检查与竞赛要求教师本人内容）。
5. **不编造教材与文献**。教材名称、版次、出版社、参考文献一律来自教师材料，否则 `【待补：…】`。
6. **不引政策条款号**。课程思政、培养方案、毕业要求只写「按学校/学院相关规定」「按本专业培养方案」，
   并提示教师核对。
7. **课程思政不自行发明**。教师没给融入点就留占位，不替教师决定「这节课要融入什么价值观」。
8. **分层不用贬义标签**。不写「差生」「学困生」「基础薄弱」，用具体行为描述 + 拓展/达标/基础层命名。
9. **评价性内容留人工确认位**：成绩构成、评分量规、目标达成判定一律留
   `【待教师确认：…】`，AI 只出草稿（`CONVENTIONS.md` §5）。
10. **不覆盖教师原始材料**。教师给的模板、成绩表、教学进度表只读不改，中间文件放临时目录。
11. **敏感数据本地处理**。含学生姓名/学号/成绩的文件不上传、不外发，任务结束提醒删除。
