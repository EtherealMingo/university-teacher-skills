## 二、各技能详细结果

### 1. lesson-plan（A 线单次课教案）

- 输入：概率论与数理统计·假设检验·本科二年级·90 分钟·大班，教材与学情数据故意不给。
- 产出：`draft.md` → `教案_概率论_假设检验.docx`（35 段 / 6 表，七个标题齐全）、`课件_概率论_假设检验.pptx`（11 页，overdense 为空，演讲者备注齐全）。
- 机械自检：不可测动词扫描命中 1 处「识记 / 理解」——这是分层任务表**认知层次列的合法标签**（技能自身模板 line 152 即此写法），非目标语句动词，按 needs-review 豁免。
- **自检有效性证据**：初稿教学过程时间实为 92 分钟（我误写「= 90」），靠脚本逐行抽取核对才暴露并修正为 90′。机械自检不是摆设。

### 2. quiz-generator（单元测验）

- 产出：`题库.json`（16 题，字段齐全）、`双向细目表.xlsx`（5 工作表含难度柱状图）、`试卷.docx`、`参考答案与评分要点.docx`。
- quiz_audit.py 首轮抓到 2 处真问题：
  1. 总分 104 ≠ 计划 100（多算了一道单选的 4 分）；
  2. Q04 正确项长度 26 字为干扰项均值 1.9 倍，答案被长度泄露。
  修正（论述 22→18 分、重写 Q04 选项）后重跑：**0 条问题，层次偏差全部 ≤5pp，知识点覆盖 100%**。
- **发现（公式级矛盾）**：按技能自己的难度预估公式（识记 0.90 / 理解 0.78 / 应用 0.65 / 分析 0.50）回标 P 值后，全卷预估平均分为 **59.8**，落在技能自己规定的「目标 75±5」之外。公式默认参数与目标区间存在内在矛盾，按流程应触发调题，但作为初稿记录为 needs-review，待教师定目标分后校准（技能 §4.5 本就有「考后回填实测 P」的纠偏机制）。

### 3. meeting-notices（教研会纪要）

- 素材特意埋入陷阱：「这个事要高度重视」「回头再说」「先别动，等下学期排课再说」、一处未被采纳的不同意见。
- 产出：`教研会纪要_20251112_v2待确认.docx`（七栏齐全，2 表）、`会议任务分工表.xlsx`（6 行 7 列）。
- task_gate.py：blocked=0、needs-review=0——决议/讨论/待定三栏分离有效，模糊表态未污染决议小节。
- **发现（真 bug）**：`task_gate.py` line 133 用 `row[0]`（序号列）当作任务文本来判断「看不出动作」，5 行 advisory 全部误报（任务列本身四要素齐全）。修复建议：改用 `row[1]`。advisory 级不阻断，但噪音大，会训练用户忽略告警。

### 4. grant-proposal（bounded 测试）

- 选题查重：自建 `已立项清单.xlsx`（3 条）跑 `topic_overlap.py`，三维重叠 + 风险分级正常输出，含「不构成查新报告」免责声明。
- 指南匹配矩阵：教师未提供前期成果，匹配依据一律 `【待补】`，未臆造（红线 2 守住）。
- 申报节选 draft：`[1][2]` 引用无证据卡 → 按纪律在证据卡状态节留空待补，未虚构文献。
- 范围说明：七阶段十模块全文撰写本次未跑全（属深度测试而非冒烟），选题查重、匹配矩阵、证据卡纪律、模拟评审口径四个关键点已覆盖。

### 5. office-layer（文件产出层）

- docx `md` / pptx `build` / xlsx `build` 均生成成功且 `inspect` 读回结构一致；本机无 LibreOffice，未做渲染级预览，结构验证为程序化 inspect。
- `comment` 命令：锚点命中 → placed=1 退出码 0，且包内确有 `word/comments.xml`（**真批注**，非文本伪装）；锚点未命中 → 退出码 2，与文档承诺一致。
- 发现 2 个缺陷：
  1. `spec` 的 `placeholder` 字段 docstring 标注 `bool`，实现实为**字符串**（占位文本）；传 `true` 直接 TypeError 崩溃。docstring 与实现矛盾，且无任何输入校验。
  2. `spec` 对未知 JSON schema（如 `{blocks:[...]}`）**静默产出 0 段空文档且退出码 0**，失败被完全掩盖。应报「未知字段/空 sections」错误。
